ตัวการที่แท้จริง: ฟอนต์

แอปตอนนี้ตั้งค่าฟอนต์ตัวแรกเป็น Sarabun ซึ่งเป็นฟอนต์ มีหัว ที่ถูกกำหนดให้ใช้กับเอกสารราชการไทยมาตั้งแต่ปี 2553 — สำหรับเด็ก ม.6 นี่คือหน้าตาของ “ใบงาน/หนังสือราชการ” งานวิจัยการรับรู้ตัวอักษรไทยระบุว่า ฟอนต์มีหัวอ่านว่า คลาสสิก/ทางการ ส่วนฟอนต์ไม่มีหัวอ่านว่า สมัยใหม่

03

05

สิ่งที่ผมไม่แนะนำ

ไอเดียทำไมไม่ควร
มาสคอตบนหน้าหลักวัฒนธรรมสติกเกอร์ LINE ทำให้คนไทยรับมาสคอตได้ดี แต่เสียงนักเรียนที่เจอบอกว่า “น่ารักแต่หลังบ้านวิเคราะห์ได้น้อยไป” — ความน่ารักเป็นเบ็ด ไม่ใช่เหตุผลที่อยู่ต่อ และงานวิจัยวัยรุ่นตะวันตกเตือนว่าเด็กโตปฏิเสธอะไรที่ “ทำให้รู้สึกเป็นเด็ก”
ย้อมพื้นหลังการ์ดด้วยสีวิชาสร้างสัญญาณสีอ่อน ๆ ทั้งจอ จนสีเน้นจริงจมหายไปหมด — สีจัดบนของชิ้นเล็ก = มั่นใจ / สีจัดบนพื้นที่ใหญ่ = ดูเด็ก
confetti ทุกครั้งที่ติ๊กฉลองบ่อยจนไม่มีค่า และอ่านว่าดูถูกกัน เก็บไว้ใช้ตอนถึงหมุดหมายจริง เช่น streak 7 วัน หรือจบวิชา
พาสเทลทั้งจอ / ลายมือขยุกขยิกเสี่ยงตกไปฝั่ง “แอปเด็ก” ซึ่งเป็นสิ่งที่กลุ่มนี้ปฏิเสธชัดเจน
06

ลำดับที่จะทำ

#ทำอะไรผลต่อความรู้สึกแรง
1เปลี่ยนฟอนต์เป็น IBM Plex Sans Thai (ฝัง woff2) + line-height 1.85สูงที่สุดเล็ก
2สีกลางอุ่น + มุมโค้ง 14px + ปุ่มมีมิติกดยุบสูงที่สุดเล็ก
3สีวิชาอิ่มขึ้น ใช้เป็นป้ายเต็มสี ไม่ใช่ขอบ 3pxสูงกลาง
4ตัวเลขใหญ่หนึ่งตัวต่อหน้า + ตัวเลขวิ่งสูงเล็ก
5เช็คถูกวาดเส้น + สปริงใน easing + กดปุ่มมีฟีดแบ็กกลาง-สูงเล็ก
6สีเข้มตามเวลาอ่าน (แบบ YPT) ในตารางเดือนกลางกลาง
7View Transitions ตอนสลับแท็บกลางเล็ก
8confetti เฉพาะตอนถึงหมุดหมายเฉพาะจุดกลาง

ข้อ 1–2 คือหัวใจ ทำแค่สองข้อนี้ความรู้สึกก็เปลี่ยนแล้ว โดยที่ยังไม่ต้องเพิ่มสีสักหยด

ความน่าเชื่อถือของข้อมูล — ต้องบอกตรง ๆ

  • agent ทั้ง 3 ตัวเปิดหน้าเว็บได้เกือบศูนย์ — proxy ของ sandbox คืน 403 เกือบทุกโดเมน ข้อมูลส่วนใหญ่จึงมาจากบทสรุปผลค้นหา ไม่ใช่การอ่านหน้าจริง
  • ที่ยืนยันได้จริง: browser support (จากซอร์ส MDN browser-compat-data), ค่าฟิสิกส์ confetti (จากซอร์ส canvas-confetti), และไฟล์ฟอนต์ (ผมดึงมาแปลงเองแล้ว)
  • agent ตัวหนึ่งดักข้อมูลผิดในผลค้นหาได้ — หลายบล็อกบอก scroll-driven animation รองรับ Firefox แล้ว แต่ BCD จริงบอกว่ายังอยู่หลังธง
  • ที่ไม่ได้มา: ค่าสีจริงและหน้าตาจริงของ TCASter / Dek-D / OnDemand — 403 ทุกทาง
