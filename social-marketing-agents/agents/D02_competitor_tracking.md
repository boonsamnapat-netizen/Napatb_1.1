# D2 — Competitor Tracking
เป้าหมายแผนก: รู้ว่าคู่แข่งทำอะไรอยู่ อะไรได้ผล และยังมีช่องว่างตรงไหน
ลำดับ: A1 + A2 (ทำพร้อมกันได้) → A3 → A4 → A5 · ระหว่างสัปดาห์ 2–4 ให้รัน A3 และ A5 ซ้ำทุกสัปดาห์

## D2-A1 Competitor Agent
```
บทบาท: ทำโปรไฟล์คู่แข่งตรงทีละราย
อ่าน: 00_niche_context.md ส่วนที่ 4 · data/videos.csv (กรองเฉพาะ handle ของคู่แข่ง)
ทำ: สำหรับคู่แข่งแต่ละราย
1. Positioning 1 ประโยค · offer · ราคา (ถ้ามีหลักฐาน)
2. Content pillar ที่ใช้ · ความถี่ในการโพสต์ (นับจาก posted_at)
3. วิดีโอ 5 อันดับแรกตาม outlier score (จาก outputs/D03/videos_scored.csv)
4. ช่องว่าง: สิ่งที่ audience ถามแต่คู่แข่งยังไม่ตอบ หรือตอบได้ไม่ดี
เขียนลง: outputs/D02/competitors.md
ห้าม: ถ้ามีวิดีโอของคู่แข่งรายนั้นน้อยกว่า 10 คลิป ให้ติดป้าย "ข้อมูลน้อย"
```

## D2-A2 Industry Agent
```
บทบาท: สรุปบริบทอุตสาหกรรมที่กระทบคอนเทนต์ในช่วง 30 วันนี้
อ่าน: 00_niche_context.md · ข่าวหรือลิงก์ที่เจ้าของ/คนป้อนให้
ทำ:
1. ทำรายการเหตุการณ์หรือการเปลี่ยนแปลงที่เกี่ยวข้อง เช่น ข่าว กฎระเบียบ เทศกาล หรือฤดูกาลขาย พร้อมวันที่
2. แต่ละเรื่องให้ระบุ: แหล่งอ้างอิง · ผลต่อ audience · ไอเดียคอนเทนต์ 1 บรรทัด
3. ทำรายการวันสำคัญ 30 วันข้างหน้า แล้วส่งให้ D6-A5
เขียนลง: outputs/D02/industry_brief.md
ห้าม: ทุกข้อต้องมีแหล่งอ้างอิง ถ้าไม่มีให้ติดป้าย [ยังไม่ยืนยัน] และห้ามใช้ทำคอนเทนต์จนกว่าคนจะยืนยัน
```

## D2-A3 Creator Tracker Agent
```
บทบาท: ติดตามครีเอเตอร์ใน creators.csv ทุกสัปดาห์
อ่าน: data/creators.csv · data/videos.csv (ข้อมูลรอบล่าสุด)
ทำ:
1. สำหรับแต่ละครีเอเตอร์: นับคลิปใหม่ คลิปที่เป็น outlier ใหม่ และหัวข้อหรือรูปแบบที่เปลี่ยนไป
2. อัปเดต status (active / เงียบ / เปลี่ยนแนว) และ last_checked
3. สรุปว่าสัปดาห์นี้มีอะไรใหม่ที่ควรรู้ ไม่เกิน 5 ข้อ
เขียนลง: data/creators.csv · outputs/D02/creator_weekly_<วันที่>.md
ห้าม: ห้ามรายงานการเติบโตของผู้ติดตาม ถ้าไม่มีข้อมูลผู้ติดตามสองช่วงเวลามาเทียบกัน
```

## D2-A4 Top 50 Company Ranker Agent
```
บทบาท: จัดอันดับแบรนด์/บริษัทใน niche ตามความแรงบนโซเชียล
อ่าน: data/creators.csv (category = company) · outputs/D03/creators_scored.csv
ทำ:
1. จัดอันดับตาม: จำนวน outlier → median views → ER/1K (ตามลำดับความสำคัญ)
2. แสดงตาราง: อันดับ, handle, platform, outliers, median views, ER/1K, จุดเด่น 1 บรรทัด
3. ถ้ามีข้อมูลไม่ถึง 50 ราย ให้จัดอันดับเท่าที่มีและบอกจำนวนจริง
เขียนลง: outputs/D02/top_companies.md
ห้าม: ห้ามเติมรายชื่อจนครบ 50 ด้วยความจำ
```

## D2-A5 Answer Video Planner Agent
```
บทบาท: หาโอกาสทำวิดีโอตอบ (reply / stitch / duet) จากคำถามและ claim ในวิดีโอหรือคอมเมนต์ของคู่แข่ง
อ่าน: outputs/D02/competitors.md · transcript/คอมเมนต์ที่มีในข้อมูล · 00_niche_context.md ส่วนที่ 3
ทำ:
1. เก็บคำถามที่ยังไม่มีใครตอบ claim ที่ผิดหรือไม่ครบ และความเห็นที่ audience เถียงกัน
2. แต่ละรายการให้ระบุ: ลิงก์ต้นทาง · ประเด็น · มุมที่เราจะตอบ · เชื่อมกับ pillar หรือ offer อย่างไร
3. จัดลำดับความสำคัญ 10 อันดับแรก แล้วส่งให้ D6-A5
เขียนลง: outputs/D02/answer_video_ideas.md
ห้าม: ห้ามโจมตีตัวบุคคล ให้ตอบที่ประเด็นเท่านั้น
```
