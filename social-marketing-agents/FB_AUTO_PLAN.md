# แผน Facebook Auto — Thaimart Affiliate · อุปกรณ์เสริมมือถือ/IT

## โจทย์ (จาก kickoff)
Affiliate ที่ยังไม่ได้สมัคร · ลงคลิปบน Facebook · วันละ 2–3 คลิป · AI ทำทั้งหมด · ไม่มีสินค้าจริง · อยากให้ระบบทำงานเอง

## ข้อเท็จจริงที่แผนนี้ต้องยึด (ตรวจเมื่อ 2026-11-07)
- Thaimart Affiliate ปักตะกร้าได้เฉพาะตอน Live ส่วนช่องทางอื่นใช้วิธีแชร์ **ลิงก์** (รองรับ Facebook) และต้องได้รับอนุมัติก่อน
- ยังไม่พบ API ของ Thaimart Affiliate ที่ประกาศไว้ **การเลือกสินค้าและสร้างลิงก์จึงต้องทำมือ**
- Facebook Graph API โพสต์ Reels ได้เฉพาะบน **Page** (`POST /{page-id}/video_reels` แบบ start → upload → finish)
  - สิทธิ์ที่ต้องมี: `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`
  - สเปกวิดีโอ: 3–90 วินาที · 9:16 · แนะนำ 1080×1920 · 24–60 fps
  - โพสต์ผ่าน API ได้ไม่เกิน 30 โพสต์ต่อ 24 ชั่วโมง (2–3 โพสต์ต่อวันอยู่ในเกณฑ์สบายๆ)
- Virlo รองรับ TikTok / YouTube / IG แต่ไม่รองรับ Facebook
  - งานวิจัย outlier ใน D3–D5 จึงต้องใช้คลิปจาก TikTok/IG/YT ในหมวดเดียวกัน แล้วนำมาปรับใช้กับ Facebook [สมมติฐาน: รูปแบบ hook ใช้ข้ามแพลตฟอร์มได้ ต้องพิสูจน์ด้วยผลจริงใน D9]

## Pipeline

```
[คน · ครั้งเดียวต่อสินค้า]  เลือกสินค้าใน Thaimart Affiliate → สร้างลิงก์ → เพิ่มแถวใน data/products.csv
                           (ชื่อ, ราคา, ค่าคอม %, spec จากหน้าสินค้า, รูปสินค้า, ลิงก์ affiliate)
        ↓
[อัตโนมัติ · ทุกวัน]  GitHub Actions (cron)
  1. เลือกสินค้า        หมุนเวียนตามรายการ และเพิ่มน้ำหนักให้สินค้าที่เคยชนะ (ใช้ผลจาก D9)
  2. สคริปต์             Claude API รัน prompt D7-A1→A5 + D8-A2 → hook, body, CTA, caption และผ่าน QC
  3. วิดีโอ              เสียงพากย์ AI ภาษาไทย + รูปสินค้า + ข้อความบนจอ → ffmpeg 1080×1920 ยาว 20–45 วินาที
  4. คิวรออนุมัติ        ส่งคลิปและ caption เข้า Telegram ให้กดอนุมัติ (แนะนำให้ใช้ช่วง 2 สัปดาห์แรก)
  5. โพสต์               Graph API /video_reels → ใส่ลิงก์ affiliate (ใน caption หรือคอมเมนต์แรก ต้องทดสอบว่าแบบไหนกดได้)
  6. วัดผล               ดึง insights ที่ 24/48/168 ชั่วโมง → performance_log.csv → metrics.py → D9 → สรุปเข้า Telegram
  7. ยอดขาย              คนดูยอดขายในแอป Thaimart แล้วกรอกสัปดาห์ละครั้ง (ยังไม่มี API)
```

Repo นี้มีระบบส่ง Telegram และ GitHub Actions ของระบบคริปโตอยู่แล้ว จึงนำรูปแบบนั้นมาใช้ซ้ำได้

## ความเสี่ยงที่ต้องรู้ก่อนทำ auto 100%
| ความเสี่ยง | วิธีป้องกันในระบบ |
|---|---|
| AI พูดเกินจริงหรืออ้างว่าใช้สินค้าเองแล้ว (ถือเป็นรีวิวปลอม) | prompt ห้ามพูดว่า "ใช้เอง" · spec ต้องมาจาก products.csv เท่านั้น · QC ของ D7-A5 |
| ภาพ AI ที่ทำให้สินค้าดูต่างจากของจริง | ใช้รูปจริงจากหน้าสินค้า ไม่สร้างภาพสินค้าใหม่ด้วย AI |
| สิทธิ์การใช้รูปสินค้าของร้าน | **ยังไม่รู้** ต้องถาม Thaimart หรือร้านค้า |
| นโยบายของ Meta เรื่องเนื้อหา AI และสแปม | ติดป้ายว่าเป็นเนื้อหา AI ตามนโยบายล่าสุดของ Meta (ต้องตรวจ) · ไม่โพสต์ข้อความซ้ำกัน · จำกัดไม่เกิน 3 โพสต์ต่อวัน |
| ไม่แจ้งว่าเป็นลิงก์นายหน้า | ใส่ข้อความ "ลิงก์นายหน้า" ใน caption ทุกโพสต์ |
| เงื่อนไข Thaimart เปลี่ยน (ระบบเพิ่งเปิดตัว) | ตรวจส่วนที่ 1.1 ของ niche_context ซ้ำทุก 2 สัปดาห์ |

## ลำดับงาน
1. **เจ้าของ:** สมัคร Thaimart Affiliate + เตรียม Facebook Page ← blocker
2. **D1–D5 (ทำคู่ขนานได้):** วิจัย niche และ hook จากคลิปอุปกรณ์เสริมมือถือบน TikTok/IG/YT
3. **เขียนโค้ด pipeline ข้อ 1–6** หลังได้คำตอบในส่วน "ต้องตัดสินใจ"
4. **สัปดาห์แรกที่โพสต์:** ใช้โหมดคนกดอนุมัติ → ถ้า QC ผ่าน ≥ 90% และไม่มีปัญหาเรื่องนโยบาย ค่อยเปิดโหมดโพสต์อัตโนมัติทั้งหมด

## ต้องตัดสินใจ (ยังไม่มีข้อมูล)
- มี Facebook Page แล้วหรือยัง / ชื่อ Page
- ระดับ auto: คนกดอนุมัติก่อนโพสต์ หรือให้โพสต์เองทั้งหมด
- งบค่า API ต่อเดือน (Claude, เสียงพากย์ AI)
- เสียงพากย์ AI ภาษาไทยจะใช้บริการไหน (ต้องทดสอบคุณภาพเสียงก่อนเลือก)
- เป้าหมาย 30 วัน (ยอดขาย / ยอดคลิกลิงก์ / ผู้ติดตาม Page)
