# ชุดตรวจก่อน commit

รันทุกครั้งที่แตะคลังข้อสอบหรือหน้าเว็บ — **ตัวเลขที่รายงานต้องมาจากที่นี่
ไม่ใช่จากสคริปต์ชั่วคราวที่ไม่ได้ commit** (เคยรายงาน "76/76 ผ่าน" โดยที่
เจ้าของ repo รันซ้ำเองไม่ได้เลย ซึ่งเท่ากับตัวเลขที่ตรวจสอบไม่ได้)

## 1. คลังข้อสอบ

```
python3 tools/check_bank.py
```

ตรวจ: qid ซ้ำ · โจทย์ซ้ำ · ตัวเลือกซ้ำ · answer นอกช่วง · ไม่มีคำอธิบาย ·
หัวข้อที่มีน้อยกว่า 5 ข้อ · คำอธิบายที่อ้าง "ตัวเลือก N" (พอสลับเฉลยแล้วชี้ผิด) ·
**การกระจายตำแหน่งเฉลย** (ไม่มีช่องไหนเกิน 35%)

## 2. หน้าเว็บ

ต้องมีเซิร์ฟเวอร์ก่อน:
```
python3 tcas_cli.py export
python3 -m http.server -d web/dist 8765 &
npm i playwright        # ครั้งแรกครั้งเดียว
node tools/check_app.mjs      # 6 หน้า × 2 ธีม × 2 ความกว้าง
node tools/check_venue.mjs    # ฟีเจอร์สนามสอบ + ความเป็นส่วนตัว
```

`check_app.mjs` ตรวจ: สกรอลล์แนวนอน · ปุ่มเตี้ยกว่า 40px · คอนทราสต์ต่ำกว่า
WCAG AA · JS error
`check_venue.mjs` ตรวจ: ตัวแกะข้อความ · ข้อมูลไม่ออกนอกเครื่อง · LOCATION
ในไฟล์ปฏิทิน · ไฟล์สำรองพาไปด้วย
