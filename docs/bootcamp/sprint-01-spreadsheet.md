## ทำไมต้องเริ่มที่สเปรดชีต

คนเรียน data ส่วนใหญ่อยากกระโดดไป Python หรือ ML ทันที แล้วพลาดสิ่งสำคัญ:
สเปรดชีตสอน **วิธีคิดแบบตาราง** ซึ่งเป็นรากของทุกอย่างที่จะเรียนต่อจากนี้

- `VLOOKUP` คือ `JOIN` ของ SQL (Sprint 2)
- `FILTER` คือ `WHERE` (Sprint 2) และ boolean masking ของ pandas (Sprint 5)
- Pivot table คือ `GROUP BY` (Sprint 2) และ `.groupby()` (Sprint 5)

เรียนแนวคิดพวกนี้ในที่ที่ **เห็นผลทันทีทุกครั้งที่พิมพ์** ง่ายกว่าเรียนตอนที่ต้องสู้กับ
syntax error ไปด้วย ถ้าเข้าใจ 3 อย่างนี้ใน Sheets แล้ว Sprint 2 กับ 5 จะง่ายขึ้นครึ่งหนึ่ง

## สัปดาห์ 2 — สูตรที่ต้องใช้เป็น

### เรียน (2 ชม.)

**กลุ่มที่ 1 — คำนวณพื้นฐาน**
`SUM` `AVERAGE` `MEDIAN` `MIN` `MAX` `COUNT` `COUNTA` `STDEV`

⚠️ `AVERAGE` กับ `MEDIAN` ต่างกันมากในข้อมูลการเงิน ลองคำนวณทั้งสองอย่างกับ
`Change%` ของ BTC แล้วดูว่าต่างกันเท่าไหร่ — ความต่างนั้นคือ "หางอ้วน" ของตลาดคริปโต
เรื่องนี้จะกลับมาหลอกคุณอีกครั้งใน Sprint 7

**กลุ่มที่ 2 — เงื่อนไข**
`IF` `IFS` `SUMIF(S)` `COUNTIF(S)` `AVERAGEIF(S)`

**กลุ่มที่ 3 — ค้นหา (สำคัญที่สุด)**
`VLOOKUP` `XLOOKUP` `INDEX`+`MATCH`

ทำไมต้องรู้ทั้งสาม: `VLOOKUP` หาได้แต่ทางขวาและพังเวลาแทรกคอลัมน์
`INDEX`+`MATCH` ไม่มีข้อจำกัดนั้น ส่วน `XLOOKUP` ใหม่กว่าและง่ายกว่าทั้งคู่
ในงานจริงคุณจะเจอไฟล์เก่าที่ใช้ `VLOOKUP` จึงต้องอ่านออก

**กลุ่มที่ 4 — ข้อความและวันที่**
`LEFT` `RIGHT` `MID` `LEN` `TRIM` `SPLIT` `CONCATENATE`
`DATE` `YEAR` `MONTH` `DAY` `WEEKDAY` `EOMONTH` `DATEDIF`

**กลุ่มที่ 5 — สูตรอาเรย์**
`FILTER` `SORT` `UNIQUE` `QUERY` `ARRAYFORMULA`

`QUERY` คือประตูสู่ SQL — syntax แทบเหมือนกัน:
```
=QUERY(A:F, "SELECT A, E WHERE E > 50000 ORDER BY E DESC LIMIT 10", 1)
```
เขียนอันนี้เป็นแล้ว Sprint 2 จะรู้สึกคุ้นทันที

### ฝึก (2 ชม.)

1. ทำตาราง lookup: แท็บหนึ่งเก็บ `symbol, ชื่อเต็ม, หมวด (L1/DeFi/Meme)` อีกแท็บดึงชื่อเต็มมาด้วย `XLOOKUP`
2. ใช้ `QUERY` หา: วันทั้งหมดในปี 2021 ที่ BTC ปิดเหนือ 60,000
3. ใช้ `WEEKDAY` + `AVERAGEIF` หาว่าวันไหนของสัปดาห์ BTC ให้ผลตอบแทนเฉลี่ยดีที่สุด
4. ✋ ข้อ 3 ได้คำตอบแล้ว **อย่าเพิ่งเชื่อ** — จดไว้ว่าคุณจะทดสอบมันจริงจังใน Sprint 7

## สัปดาห์ 3 — Pivot table + โปรเจกต์

### เรียน (2 ชม.)

**Pivot table** — เครื่องมือสรุปข้อมูลที่ทรงพลังที่สุดในสเปรดชีต
4 ช่องที่ต้องเข้าใจ: Rows (แบ่งกลุ่มตามอะไร), Columns (แบ่งย่อยอีกชั้น),
Values (คำนวณอะไร), Filters (ตัดอะไรออก)

เทียบกับสิ่งที่จะเจอต่อไป:
```
Pivot: Rows=เดือน, Values=AVERAGE(Change%)
SQL  : SELECT month, AVG(change_pct) FROM prices GROUP BY month
pandas: df.groupby('month')['change_pct'].mean()
```
สามอันนี้คือของเดียวกัน — จำภาพนี้ไว้ให้ขึ้นใจ

**Conditional formatting** — ระบายสีตามเงื่อนไข ใช้ทำ heatmap ง่าย ๆ
**Data validation** — ทำ dropdown กันคนกรอกมั่ว

### โปรเจกต์ส่ง — Crypto Tracker (3 ชม.)

สร้าง Google Sheets 1 ไฟล์ 4 แท็บ:

**แท็บ `raw`** — ข้อมูลดิบ BTC + ETH + SOL (import จาก CSV)

**แท็บ `daily`** — ต่อคอลัมน์คำนวณ:
- `Change%` — % เปลี่ยนแปลงรายวัน
- `Range%` — `(High-Low)/Open` เป็นตัวแทนความผันผวนของวัน
- `MA20` — ค่าเฉลี่ยราคาปิด 20 วัน
- `Above_MA` — TRUE/FALSE ว่าปิดเหนือ MA20 ไหม
- `DayOfWeek` — ชื่อวันในสัปดาห์

**แท็บ `summary`** — pivot 3 ตัว:
1. ผลตอบแทนเฉลี่ยรายเดือน แยกตามเหรียญ
2. ความผันผวนเฉลี่ยรายปี แยกตามเหรียญ
3. จำนวนวันที่ปิดเหนือ MA20 เทียบใต้ MA20 แยกตามปี

**แท็บ `insight`** — เขียนภาษาคนล้วน ๆ ไม่มีสูตร:
- 3 สิ่งที่คุณเจอ พร้อมตัวเลขอ้างอิง
- 1 สิ่งที่ข้อมูลนี้**ตอบไม่ได้** และต้องใช้อะไรเพิ่มถึงจะตอบได้

ข้อสุดท้ายสำคัญที่สุด — คนที่แยกออกว่าข้อมูลตอบอะไรไม่ได้ คือคนที่ใช้ข้อมูลเป็น

**เกณฑ์ผ่าน:** ทุกสูตรทำงานถูกต้อง, ไม่มีเลขที่พิมพ์มือทับสูตร, แท็บ `insight` มีตัวเลขอ้างอิงทุกข้อ

## Checkpoint — ตอบให้ได้โดยไม่เปิดโน้ต

1. `VLOOKUP` กับ `INDEX`+`MATCH` ต่างกันยังไง และเมื่อไหร่ `VLOOKUP` จะพัง
2. เขียน `QUERY` ที่ดึงเฉพาะแถวที่ `Volume` มากกว่าค่าเฉลี่ย แล้วเรียงตาม `Date` ใหม่ไปเก่า
3. Pivot table เทียบกับ `GROUP BY` ของ SQL ยังไง — ช่องไหนตรงกับส่วนไหน
4. `AVERAGE` กับ `MEDIAN` ของผลตอบแทนรายวัน อันไหนน่าเชื่อกว่าในตลาดคริปโต เพราะอะไร
5. บอกมา 1 อย่างที่ข้อมูล OHLCV รายวัน **ตอบไม่ได้** เกี่ยวกับพฤติกรรมราคา

> ข้อ 5 ไม่มีเฉลยตายตัว ตัวอย่างที่รับได้: ราคาแตะ High ก่อนหรือ Low ก่อนภายในวันนั้น —
> ข้อมูลรายวันไม่บอกลำดับ ซึ่งเป็นปัญหาใหญ่มากตอนทำ backtest ใน Sprint 9
