# Data Science Bootcamp — ฉบับ Napat

หลักสูตร Data Science / Data Analyst 10 sprints สำหรับคนเริ่มจากศูนย์
เรียนด้วยตัวเอง ~5 ชม./สัปดาห์ รวม 32 สัปดาห์ (~8 เดือน, ~160 ชม.)

**ภาษา:** Python อย่างเดียว (ไม่มี R)
**ชุดข้อมูลหลัก:** ข้อมูลคริปโตจริงใน repo นี้ — `data/real/crypto/*.csv` (รายวัน ตั้งแต่ 2018)
และ `data/real/crypto_1h/*.csv` (รายชั่วโมง) 20 เหรียญ

## ปรัชญาของหลักสูตรนี้ (อ่านก่อนเริ่ม)

**1. ทุก sprint จบด้วยของที่ใช้งานได้จริง ไม่ใช่โน้ตสรุป**
ถ้าจบ sprint แล้วไม่มีไฟล์ที่รันได้/เปิดดูได้ แปลว่ายังไม่จบ

**2. ห้ามคัดลอกคำตอบ**
ทุกแบบฝึกหัดให้ลองเองก่อนอย่างน้อย 20 นาที ติดแล้วค่อยถาม
การถาม Claude ว่า "ทำไมโค้ดนี้ error" ดีกว่าถามว่า "เขียนโค้ดนี้ให้หน่อย" มาก

**3. ข้อมูลจริงมันสกปรก และนั่นคือบทเรียน**
ไฟล์ CSV ใน repo นี้มีวันหาย มีค่าซ้ำ มีเหรียญที่เพิ่งลิสต์เลยข้อมูลสั้นกว่าเพื่อน
อย่ามองว่าเป็นบั๊ก — มองว่าเป็นข้อสอบ

**4. ตัวเลขต้องซื่อสัตย์**
กฎเดียวกับ `CLAUDE.md` ของ repo นี้: ผลลัพธ์ต้องหักค่าธรรมเนียม ต้องเป็น out-of-sample
และถ้าไม่รู้ให้บอกว่าไม่รู้ หลักสูตรนี้ให้ค่ากับ "โมเดลที่รู้ว่าตัวเองผิดตรงไหน"
มากกว่า "โมเดลที่ accuracy 99%"

**5. Sprint 9 คือหัวใจ**
คนส่วนใหญ่เรียน ML แล้วหยุดที่ Sprint 8 — ได้โมเดล accuracy สวย ๆ แล้วดีใจ
Sprint 9 คือ sprint ที่จะทำให้คุณรู้ว่าโมเดลนั้นโกงตัวเองยังไง
ถ้าจะข้าม sprint ไหน อย่าข้ามอันนี้

## เตรียมตัวก่อนเริ่ม (สัปดาห์ 0)

### 1. เครื่องมือที่ต้องมี — ฟรีทั้งหมด

| เครื่องมือ | ใช้ทำอะไร | เริ่มใช้ sprint |
|---|---|---|
| Google Sheets | สเปรดชีต | 1 |
| [DB Browser for SQLite](https://sqlitebrowser.org/) หรือ [sqliteonline.com](https://sqliteonline.com/) | ฐานข้อมูล | 2 |
| [Google Colab](https://colab.research.google.com/) | เขียน Python ในเบราว์เซอร์ ไม่ต้องติดตั้ง | 3 |
| VS Code + Python | เขียนโค้ดจริงบนเครื่อง | 4 |
| GitHub | เก็บงาน + ทำพอร์ตโฟลิโอ | 4 |
| [Looker Studio](https://lookerstudio.google.com/) | แดชบอร์ด | 10 |

เริ่มที่ Colab ก่อน แล้วค่อยย้ายมา VS Code ตอน Sprint 4 — อย่าเสียเวลาสัปดาห์แรก
ไปกับการติดตั้ง Python บนเครื่องให้สำเร็จ

### 2. ดึงข้อมูลคริปโตมาไว้ใช้

ไฟล์ CSV อยู่คนละ branch กับหลักสูตรนี้ ดึงมาด้วย:

```bash
git fetch origin claude/crypto-signal-system-kcf8vq
git checkout FETCH_HEAD -- data/real/
ls data/real/crypto/        # ควรเห็น 20 ไฟล์ .csv
```

หน้าตาข้อมูล — `data/real/crypto/BTCUSDT.csv`:

```
Date,Open,High,Low,Close,Volume
2018-01-01,14112.20,14112.20,13154.70,13657.20,10291200000
2018-01-02,13625.00,15444.60,13163.60,14982.10,16846600192
```

- **รายวัน** (`crypto/`) — ตั้งแต่ปี 2018, ~3,100 แถวต่อเหรียญ, คอลัมน์แรกชื่อ `Date`
- **รายชั่วโมง** (`crypto_1h/`) — ~730 วันย้อนหลัง, คอลัมน์แรกชื่อ `Datetime` (มี timezone)

⚠️ ชื่อคอลัมน์แรกไม่เหมือนกันระหว่างสองโฟลเดอร์ — เจอ error ตอน Sprint 5 อย่าเพิ่งตกใจ

### 3. สร้างที่เก็บงาน

```bash
mkdir -p bootcamp/{sprint01,sprint02,sprint03,sprint04,sprint05,sprint06,sprint07,sprint08,sprint09,sprint10}
```

ทุกโปรเจกต์ที่ส่งให้เก็บในโฟลเดอร์ของ sprint นั้น พร้อม `README.md` สั้น ๆ ว่าทำอะไร
พอจบ Sprint 10 โฟลเดอร์นี้จะกลายเป็นพอร์ตโฟลิโอของคุณ

## จังหวะการเรียนต่อสัปดาห์ (5 ชม.)

| ช่วง | เวลา | ทำอะไร |
|---|---|---|
| เรียน | 2 ชม. | อ่าน/ดูเนื้อหาของสัปดาห์นั้น จดสิ่งที่ไม่เข้าใจ |
| ฝึก | 2 ชม. | ทำแบบฝึกหัด — ส่วนนี้ห้ามข้าม เป็นส่วนที่ทำให้จำได้จริง |
| ทบทวน | 1 ชม. | เขียนสรุปสิ่งที่เรียน 5 บรรทัด + ทำ checkpoint |

**สัปดาห์ที่ไม่มีเวลา** ให้ทำแค่ 1 ชม. ส่วน "ฝึก" ดีกว่าหยุดทั้งสัปดาห์
ความต่อเนื่องสำคัญกว่าความเข้มข้น — หลักสูตร 8 เดือนพังเพราะหยุด 3 สัปดาห์แล้วไม่กลับมา
ไม่ใช่เพราะสัปดาห์ไหนทำน้อยไป

## เกณฑ์ผ่านแต่ละ Sprint

ทุก sprint มีส่วน **Checkpoint** ท้ายไฟล์ เป็นคำถาม 5 ข้อที่ต้องตอบได้โดยไม่เปิดโน้ต
ถ้าตอบไม่ได้เกิน 2 ข้อ ให้ทวน sprint นั้นอีกสัปดาห์ก่อนไปต่อ — อย่าปล่อยผ่าน
เพราะ Sprint 5–9 ต่อยอดจากของเดิมทั้งหมด
