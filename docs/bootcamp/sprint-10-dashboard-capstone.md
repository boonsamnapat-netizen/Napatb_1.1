## สัปดาห์ 31 — Dashboard

### เรียน (2 ชม.)

**Dashboard ที่ดีต่างจากกราฟกองรวมกันยังไง**

| Dashboard ดี | Dashboard แย่ |
|---|---|
| ตอบคำถามเดียวชัดเจน | แสดงทุกอย่างที่วาดได้ |
| ตัวเลขสำคัญที่สุดอยู่บนซ้าย | เรียงตามลำดับที่นึกออก |
| ดูจบใน 30 วินาที | ต้องเลื่อนหา |
| บอกว่าต้องทำอะไรต่อ | บอกแค่ว่าเกิดอะไรขึ้น |
| มีวันที่อัปเดตล่าสุด | ไม่รู้ว่าข้อมูลเก่าแค่ไหน |

**หลักการจัดวาง** — คนอ่านจากบนซ้ายเป็นตัว F
```
┌─────────────────────────────────────────┐
│  ตัวเลขสำคัญ 3–5 ตัว (KPI cards)         │
├──────────────────────┬──────────────────┤
│  กราฟหลัก (ใหญ่สุด)   │  กราฟรอง          │
├──────────────────────┴──────────────────┤
│  ตารางรายละเอียด                          │
└─────────────────────────────────────────┘
```

**เลือกเครื่องมือ**

| เครื่องมือ | ดี | ไม่ดี |
|---|---|---|
| **Looker Studio** | ฟรี แชร์ง่าย ไม่ต้องเขียนโค้ด ต่อ Google Sheets ได้ | คำนวณซับซ้อนไม่ได้ |
| **Streamlit** | Python ล้วน ใส่โมเดลเข้าไปได้ | ต้องหาที่ host |
| **Tableau Public** | สวย ชุมชนใหญ่ | งานต้องเป็นสาธารณะ |

ทำทั้ง Looker Studio และ Streamlit อย่างละอัน — ตลาดงานถาม Looker/Power BI บ่อย
แต่ Streamlit แสดงว่าคุณเขียนโค้ดเป็น

**Streamlit เบื้องต้น**
```python
import streamlit as st

st.set_page_config(page_title="Crypto Dashboard", layout="wide")
st.title("ภาพรวมตลาดคริปโต")

symbol = st.sidebar.selectbox("เลือกเหรียญ", symbols)
days   = st.sidebar.slider("ย้อนหลัง (วัน)", 30, 730, 180)

c1, c2, c3, c4 = st.columns(4)
c1.metric("ราคาปัจจุบัน", f"${price:,.0f}", f"{change:+.2%}")
c2.metric("ผลตอบแทน 30 วัน", f"{r30:+.1%}")
c3.metric("ความผันผวนรายปี", f"{vol:.1%}")
c4.metric("Drawdown ปัจจุบัน", f"{dd:.1%}")

st.plotly_chart(fig, use_container_width=True)

@st.cache_data                    # สำคัญ — ไม่งั้นโหลดข้อมูลใหม่ทุกครั้งที่คลิก
def load(symbol): ...
```

รันด้วย `streamlit run app.py` deploy ฟรีที่ [share.streamlit.io](https://share.streamlit.io/)

3. สร้าง Streamlit app ที่เลือกเหรียญได้และแสดงกราฟ + สถิติ
4. Deploy Streamlit ขึ้น share.streamlit.io ให้เปิดจากมือถือได้

## สัปดาห์ 32 — Capstone และพอร์ตโฟลิโอ

### Capstone Project (5 ชม.)

**เลือก 1 โจทย์**

**ตัวเลือก A — Crypto Market Monitor**
Dashboard ที่คนถือคริปโตเปิดดูทุกเช้าแล้วได้ประโยชน์จริง:
- ภาพรวมตลาด 20 เหรียญ พร้อมสัญญาณเทคนิค
- ความสัมพันธ์ระหว่างเหรียญ + คำเตือนเมื่อพอร์ตกระจุกตัว
- Regime ปัจจุบัน (bull/bear/sideways) พร้อมเกณฑ์ที่ใช้ตัดสิน
- คำเตือนความเสี่ยง: drawdown, ความผันผวนที่พุ่งขึ้น

**ตัวเลือก B — Strategy Report Card**
รายงานประเมินกลยุทธ์อย่างซื่อสัตย์ ที่คนอ่านตัดสินใจได้ว่าจะใช้ไหม:
- นิยามกลยุทธ์ให้ชัดเจน (กฎเข้า/ออก/ขนาดโพสิชัน)
- Walk-forward results หักค่าธรรมเนียม
- เทียบกับ baseline
- ผลแยกตาม regime และแยกตามเหรียญ
- ส่วน "กลยุทธ์นี้จะพังเมื่อไหร่" ที่เป็นรูปธรรม

**ตัวเลือก C — โจทย์ของคุณเอง**
ต้องใช้ทักษะจากอย่างน้อย 6 sprint และมีผลลัพธ์ที่คนอื่นใช้ได้

**ข้อกำหนดร่วม**
- ใช้ทักษะจากอย่างน้อย 6 sprint
- มี dashboard หรือรายงานที่เปิดดูได้จากลิงก์
- มี `README.md` ที่คนไม่รู้จักโปรเจกต์อ่านแล้วเข้าใจใน 2 นาที
- โค้ดรันซ้ำได้ตั้งแต่ต้น (`requirements.txt` + คำสั่งรันชัดเจน)
- **มีส่วน "ข้อจำกัดและสิ่งที่งานนี้ไม่ได้พิสูจน์"**

ข้อสุดท้ายคือสิ่งที่ทำให้งานคุณต่างจากงานคนอื่นในตลาด
คนส่วนใหญ่โชว์แต่ผลดี คนที่บอกข้อจำกัดตัวเองได้ คือคนที่เชื่อถือได้
