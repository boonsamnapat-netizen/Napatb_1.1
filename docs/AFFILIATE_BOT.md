# Affiliate Clip Bot — บอททำคลิปปักตะกร้า

ส่ง **รูปสินค้า** เข้า Telegram → บอทหาสินค้า → ทำคลิป 8 วิ → ให้ตรวจ → เลือกลิงก์
(ถูกสุด / ขายดีสุด / คอมเยอะสุด) → ยืนยันอีกครั้ง → ส่งไฟล์ + แคปชั่นกลับมาให้โพสต์เอง

ระบบนี้**แยกจากระบบสัญญาณคริปโตทั้งหมด** — ไม่ import `src/signal/` และไม่แตะไฟล์ของมัน

## Flow

```
📷 รูปสินค้า
   └─▶ อ่านชื่อสินค้าจากรูป (ANTHROPIC_API_KEY) หรือให้พิมพ์/วางลิงก์เอง
        └─▶ [confirm_product]  ✅ ใช่ · ✍️ ส่งลิงก์เอง · ❌ ยกเลิก
             └─▶ เรนเดอร์คลิป 8 วิ
                  └─▶ [confirm_video]  ✅ OK · 🔄 ทำใหม่ · ❌ ยกเลิก
                       └─▶ [choose_link]  💰 ถูกสุด · 🔥 ขายดีสุด · 💸 คอมเยอะสุด
                            └─▶ [final_confirm]  ✅ ยืนยัน · 🔄 เปลี่ยนลิงก์ · ❌ ยกเลิก
                                 └─▶ [delivered] ส่งไฟล์ .mp4 + แคปชั่น + แฮชแท็ก + ลิงก์
```

สถานะทุกงานเก็บใน `data/affiliate_state.json` — บอทหยุดกลางทางแล้วรันต่อได้

## รันยังไง

```bash
python affiliate_bot.py --serve      # long-poll ตลอดเวลา (VPS / คอมที่บ้าน) ← ตอบไว
python affiliate_bot.py --once       # ดึง update ที่ค้าง 1 รอบแล้วจบ (GitHub Actions)
python affiliate_bot.py --selftest --image รูป.jpg   # ทดสอบเรนเดอร์ ไม่ต่อ Telegram
```

ไม่ได้ตั้ง `TELEGRAM_BOT_TOKEN` → ทุกการส่งจะถูก log แทน (dry-run) ใช้ทดสอบได้

## ตั้งค่าครั้งแรก

1. `@BotFather` → `/newbot` → เอา token
2. Repo Settings → Secrets and variables → Actions → เพิ่ม `TELEGRAM_BOT_TOKEN`
3. (ถ้ามี) เพิ่ม `ANTHROPIC_API_KEY` และ `AFFILIATE_VIDEO_API_KEY`
4. ทักบอทด้วย `/start` แล้วส่งรูปสินค้าได้เลย

คำสั่งในแชท: `/start` `/help` `/status` `/cancel`

## วิธีหาสินค้าจากรูปที่ดีที่สุด (และไม่ต้องมี API)

**ใช้ image search ในแอปของแพลตฟอร์มเอง แล้วก๊อปลิงก์มาวางให้บอท**

- TikTok Shop → Creator Toolkit → **Search by Image**
- Lazada → ไอคอน **สแกน** (Image Search — ใช้ได้เฉพาะแอปมือถือ)

แม่นกว่าทุกวิธีที่เราสร้างเองได้ เพราะมันค้นกับแคตตาล็อกจริงของแพลตฟอร์ม ไม่มีค่าใช้จ่าย
และไม่มีความเสี่ยง ToS — บอทถูกออกแบบให้รับลิงก์ที่วางมาอยู่แล้ว

ทางเลือกรอง: ตั้ง `ANTHROPIC_API_KEY` ให้บอทอ่านชื่อสินค้าจากรูปแล้วค้นด้วยคีย์เวิร์ด
(แม่นเท่าที่อ่านฉลากออก — prompt สั่งห้ามเดายี่ห้อไว้แล้ว)

**ไม่แนะนำ: scrape หน้าค้นหาของแพลตฟอร์ม** — ผิด ToS และเสี่ยงบัญชี creator
ที่เป็นตัวหาเงินของคุณเอง

## ส่งลิงก์เองให้เทียบได้ (ยังไม่ต้องมี API)

บรรทัดละ 1 รายการ — ใส่แค่ลิงก์ก็ได้ หรือใส่ตัวเลขคั่นด้วย `|` เพื่อให้เทียบได้ครบ 3 แบบ:

```
ชื่อสินค้า | ลิงก์ | ราคา | ยอดขาย | คอม%
กระติกน้ำ A | https://lazada.co.th/a | 199 | 1200 | 8
กระติกน้ำ B | https://lazada.co.th/b | 149 | 300  | 15
```

ตัวเลือกไหนไม่มีข้อมูลรองรับ ปุ่มนั้นจะไม่ขึ้น และบอทจะบอกว่าขาดอะไร

> **"คอมเยอะสุด" = เงินบาทที่ได้จริง** (`ราคา × คอม%`) ไม่ใช่ % ที่สูงที่สุด
> ในตัวอย่างข้างบน B ชนะ (149×15% = ฿22) แม้ราคาถูกกว่า A (199×8% = ฿16)
> ถ้าไม่รู้ราคาเลย ระบบจะถอยไปเทียบด้วย % แทน
>
> ⚠️ **ถ้าทุกตัวคอม % เท่ากัน** (affiliate network มักให้เรตระดับหมวดหมู่ ไม่ใช่ราย
> สินค้า) การจัดอันดับนี้จะกลายเป็น "ราคาแพงสุด" ไปโดยปริยาย — บอทจะเตือนในหน้า
> ยืนยันครั้งสุดท้ายเมื่อเจอกรณีนี้

## ความปลอดภัย / กันเงินไหล

| คีย์ | ทำอะไร |
|---|---|
| `allowed_user_ids` | **ตั้งอันนี้ก่อนเปิดใช้จริง** ว่างไว้ = ใครก็ตามที่เจอชื่อบอทสั่งเรนเดอร์ได้ (= เผาเงินคุณ) ทักบอทแล้วมันจะบอก user id ของคุณเอง |
| `daily_render_limit` | เพดานเรนเดอร์ต่อวัน (UTC) นับ**ก่อน**เรียก vendor เพราะเรนเดอร์ที่ fail ก็เสียเงินแล้ว |

บอทยังกันการ**กดปุ่มซ้ำ**ด้วย: ทุก callback ถูกเช็คกับ state ปัจจุบันของงาน และปุ่มจะถูก
ถอดออกทันทีที่ขั้นนั้นถูกใช้ไปแล้ว — เลื่อนขึ้นไปกดข้อความเก่าไม่ทำให้เรนเดอร์ซ้ำ

## Config — `config/affiliate.yaml`

| คีย์ | ทำอะไร |
|---|---|
| `video.provider` | `ai` หรือ `ffmpeg` — `ai` ที่ยังไม่ตั้ง endpoint จะถอยไปใช้ ffmpeg เอง |
| `video.ai.*` | adapter แบบ generic: ตั้ง `submit_url`, `headers`, `payload`, `result_path` ได้เอง ใช้ได้กับเจ้าไหนก็ได้ |
| `video.ffmpeg.font_path` | ฟอนต์สำหรับ text บนคลิป (ต้องรองรับไทย) `null` = หาให้อัตโนมัติ |
| `finders.lazada` / `finders.tiktok` | ปิดอยู่ เปิดเมื่อได้ API key |
| `state_path` | ไฟล์สถานะงาน |

`${ชื่อตัวแปร}` ใน YAML จะถูกแทนด้วยค่าจาก environment ตอนรัน — key ไม่ต้องอยู่ในไฟล์

## ต่อ API เพิ่มทีหลัง

### Image-to-video

`config/affiliate.yaml` มีบล็อก **Replicate** กรอกไว้พร้อมแล้ว — ตั้ง
`REPLICATE_API_TOKEN` แล้วเปลี่ยน `video.provider` เป็น `ai` ก็ใช้ได้เลย
เปลี่ยนโมเดล/ราคา = แก้บรรทัด `model:` บรรทัดเดียว

Replicate ถูกเลือกเพราะ **poll ครั้งเดียวได้ทั้ง `status` และ `output`** ซึ่งตรงกับ
adapter นี้พอดี ส่วนเจ้าอื่นต้องแก้โค้ดเพิ่ม:

| เจ้า | ติดตรงไหน | ต้องแก้ |
|---|---|---|
| Replicate | — | ไม่ต้องแก้ ใช้ได้เลย |
| Runway | ได้เหมือนกัน แต่ **ยาวได้แค่ 5 หรือ 10 วิ ไม่มี 8** | ไม่ต้องแก้โค้ด |
| Google Veo (ตรง) | ต้องใส่ auth ตอนโหลดไฟล์ | `authenticated_download: true` (ทำไว้แล้ว) |
| fal.ai / Pika | `/status` ไม่มี output ต้องยิงอีกรอบ | `result_url:` (ทำไว้แล้ว) |
| MiniMax/Hailuo | 3 hop และไม่มี 8 วิ (มี 6 หรือ 10) | ต้องเพิ่ม `result_id_path` |
| Kling (ตรง) | ต้องเซ็น JWT ทุก request | ต้องเขียน hook เพิ่ม — หรือเรียกผ่าน Replicate แทน |
| Segmind (sync) | ตอบเป็นไฟล์ mp4 ดิบ ไม่ใช่ JSON | ยังไม่รองรับ |

> ราคาที่ agent หามาให้ (Veo 3.1 Fast ≈ $1.20 ต่อคลิป 8 วิ, Seedance ≈ $0.16)
> **ยังไม่ได้ยืนยันจากหน้า pricing โดยตรง** เพราะแซนด์บ็อกซ์เปิดเว็บไม่ได้ —
> เช็คเองก่อนผูกบัตร รวมถึงชื่อ model slug ด้วย
>
> บทเรียนจริงจากโปรเจกต์ [vibevid](https://github.com/LCSantos-cmt/vibevid) ที่ทำ
> pipeline Veo 3 แบบเดียวกัน: **หยุดโปรเจกต์เพราะค่า API $15–40 ต่อสินค้า 1 ชิ้น**
> ดังนั้น default ของ repo นี้จึงเป็น `ffmpeg` (ฟรี) และเปิด `ai` เฉพาะคลิปที่จะโพสต์จริง

### Affiliate search

`src/affiliate/products.py` มีโครงรออยู่ ทุกตัว raise `ProviderNotConfigured`
ต้องเติม `search()` เอง แล้วเปิด `finders.<ชื่อ>.enabled: true`

**ทางที่น่าจะเป็นจริงที่สุดคือ affiliate network ไม่ใช่ API ของแพลตฟอร์มเอง** —
`NetworkFinder` (Involve Asia / ACCESSTRADE TH) เพราะสมัคร publisher ได้ฟรีโดยไม่ต้อง
จดบริษัท และทั้งคู่มีทั้ง Lazada Thailand และ TikTok Shop Thailand
ส่วน Lazada Open Platform ต้องใช้ใบทะเบียนพาณิชย์ และ "Lazada Affiliate API"
**ยืนยันไม่ได้ว่ามีอยู่จริง** (เจอแต่บล็อกของ vendor เจ้าเดียว ไม่มีหน้าเอกสารของ Lazada เอง)

ข้อควรรู้ก่อนลงแรง: network มักให้คอมเป็น **เรตระดับแคมเปญ/หมวดหมู่** และ **ไม่มี
ยอดขายรายสินค้า** → กลยุทธ์ `ขายดีสุด` อาจใช้ไม่ได้เลย และ `คอมเยอะสุด` จะเสื่อมเป็น
"แพงสุด" (บอทเตือนให้แล้ว)

## ข้อจำกัดที่รู้อยู่แล้ว

- **GitHub Actions ตอบช้า** — cron ของ GitHub เป็น best-effort มักดีเลย์ 10–30 นาที
  ถ้าอยากให้บอทตอบทันที ต้องรัน `--serve` บนเครื่องที่เปิดตลอด
- **ยังไม่มี API ค้นสินค้า** — ตอนนี้ต้องวางลิงก์เอง การหา "สินค้าเดียวกันจากรูป"
  แบบอัตโนมัติยังทำไม่ได้จนกว่าจะได้สิทธิ์เข้า affiliate API
- **ไม่อัพโหลดขึ้นแพลตฟอร์มให้** — ยืนยันแล้วว่าตัดสินใจถูก: TikTok Content Posting API
  ต้องมี **เว็บไซต์สาธารณะ + Privacy Policy + ToS** ถึงจะผ่าน app review และเอกสารระบุ
  ชัดว่า "แอปที่ยังอยู่ในขั้น development หรือ testing จะไม่ได้รับอนุมัติ" ส่วนแอปที่ยังไม่
  ผ่าน audit จะโพสต์ได้แบบ **private เท่านั้น** และจำกัด 5 ผู้ใช้ต่อ 24 ชม.
  ยังไม่ยืนยันด้วยซ้ำว่า API ปักตะกร้า (แนบสินค้าเข้าคลิป) ได้หรือเปล่า — ถ้าไม่ได้
  การโพสต์อัตโนมัติก็ไร้ความหมายตั้งแต่แรก
- **`--serve` กับ workflow ห้ามรันพร้อมกัน** — Telegram ให้ poll ได้ทีละตัวต่อ 1 token
  รันคู่กันจะได้ HTTP 409 และ update หาย เลือกอย่างใดอย่างหนึ่ง
- **ไม่มีโปรเจกต์ open-source ตัวไหนรันบอท Telegram บน GitHub Actions** — ทุกตัวที่หาเจอ
  รันเป็น long-running process ทางนี้ไม่มีคนเดินมาก่อน
- **ffmpeg + ข้อความไทย** — ffmpeg เรนเดอร์สระ/วรรณยุกต์ไทยได้ไม่สวยเสมอไป ถ้าฟอนต์
  ที่เจอไม่รองรับไทย บอทจะเรนเดอร์คลิปเปล่า ๆ แทนที่จะได้กล่องสี่เหลี่ยม ข้อความยังอยู่
  ในแคปชั่นครบ — จะเอาไปใส่ตัวอักษรใน CapCut เองก็ได้
- **ยังไม่ได้ทดสอบเรนเดอร์จริง** — แซนด์บ็อกซ์ที่เขียนโค้ดนี้ไม่มี ffmpeg ติดตั้ง
  โค้ดส่วน state machine / การเลือกลิงก์ / แคปชั่น ผ่านเทสต์ครบ แต่ path การเรนเดอร์
  ต้องรันจริงบนเครื่องที่มี ffmpeg ก่อนจึงจะยืนยันได้
