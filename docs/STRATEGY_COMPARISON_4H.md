รัน 5 กลยุทธ์ผ่าน **เครื่องยนต์เดียวกัน** (entry แท่งถัดไป open, SL/TP เป็น R,
time-stop 30 แท่ง, fee 0.05%/ข้าง) บนข้อมูลจริง 6 majors เพื่อเทียบแบบแฟร์

`donchian` (breakout 20) · `ema_cross` (EMA20×50) · `supertrend` (10,3)

## ข้อสรุป

1. **บน 4H ผู้ชนะชัดเจน = EMA crossover** — บวกทุกช่วงเวลา/ทุก target และดีขึ้นเมื่อ
   ปล่อยกำไรวิ่ง (4R: **+0.20R/ไม้, PF 1.30, 290 ไม้, maxDD 15.7R**)
2. **Divergence ไม่เหมาะกับ 4H** — ติดลบทุกกรณี เพราะเป็นสัญญาณ reversal/mean-revert
   ยิ่ง target กว้างยิ่งแย่ → ของแบบนี้อยู่ที่ **1D** (1D divergence = +0.24R, ดู `DIVERGENCE_BACKTEST_RESULTS.md`)
3. **trend filter ช่วย divergence** ได้บ้าง (−0.13 → −0.05) แต่ยังไม่พอให้เป็นบวกบน 4H
4. **Donchian/Supertrend** ต้องใช้ exit แบบปล่อยวิ่ง (4R) ถึงเป็นบวก — TP แคบฆ่ามัน

### ⚠️ คำเตือนสำคัญ (อย่ามองข้าม)
**กำไรของ ema_cross กระจุกตัวที่ alt** ไม่ broad-based:
per-coin (4R, 2 ปี): SOL +26R, XRP +23R, ETH +18R **แต่ ADA −6R, BTC −3R, BNB ~0**
→ EMA cross บน 4H **ขาดทุนบน BTC** ในช่วงนี้ กำไรมาจาก 3 alt ที่เทรนด์แรง
ถ้าตลาด sideways/เปลี่ยน regime เมื่อไหร่ edge นี้อาจหาย

## คำแนะนำ
- อยากเทรด **4H จริงๆ** → ใช้ **EMA crossover + ปล่อยกำไรวิ่ง (target ≥3R หรือ trailing)**
  และโฟกัสเหรียญที่เทรนด์ชัด (อย่าคาดหวังมากกับ BTC บน 4H)
- อยากเล่น **divergence** (อย่างที่บอทเราทำ) → **1D ดีกว่า 4H มาก**
- ทางที่ robust สุดจากทั้งหมด: **1D divergence broad-based** > 4H ema_cross (กระจุก alt)
