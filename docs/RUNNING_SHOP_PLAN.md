# แผนเปิดร้านอุปกรณ์วิ่ง ถนน/เทรล — เริ่มจากศูนย์

อัปเดต: 2026-08-08

**อินพุตที่เจ้าของให้มา**
- ทุนตั้งต้น: **ต่ำกว่า 100,000 บาท** (เงินที่จมได้จริง)
- ช่องทาง: **ออนไลน์เป็นหลัก** ไม่ผูกทำเล
- สินค้าที่อยากโฟกัส: **รองเท้าวิ่ง ถนน/เทรล + เสื้อผ้า/ชุดวิ่ง**

> เอกสารนี้แยกชัดเจนระหว่าง (ก) สิ่งที่เจ้าของบอกมา (ข) ตรรกะ/โครงสร้างที่วางให้
> (ค) ตัวเลขที่เป็น **สมมติฐาน ต้องไปเช็คของจริง** — ตัวเลขทุกตัวในเอกสารนี้ที่ไม่ได้มาจาก
> เจ้าของ ให้ถือเป็นช่องว่างให้กรอก ไม่ใช่ข้อเท็จจริงของตลาด

## 1. ข้อจำกัดที่ต้องยอมรับก่อน (พูดตรง ๆ)

สินค้า 2 อย่างที่เลือก คือ 2 อย่างที่ **กินทุนหนักที่สุด** ในหมวดของวิ่ง เพราะมี "ไซส์" คูณ "สี" คูณ "เพศ"

ตัวอย่างเลขที่ทำให้เห็นภาพ (ราคาต้นทุนเป็นสมมติฐาน ต้องไปขอใบเสนอราคาจริง):

| รายการ | จำนวน SKU | ต้นทุน/ชิ้น (สมมติ) | เงินที่จม |
|---|---|---|---|
| รองเท้า 1 รุ่น 1 สี ชาย US7–US12 | 6 คู่ | 2,500–4,000 ฿ | 15,000–24,000 ฿ |
| + ผู้หญิง US5–US9 | 5 คู่ | 2,500–4,000 ฿ | 12,500–20,000 ฿ |
| **รวม 1 รุ่น 1 สี** | **11 คู่** | | **27,500–44,000 ฿** |

แปลว่า ถ้าซื้อรองเท้าเป็น "ไซส์รัน" ตั้งแต่ล็อตแรก **ทุนก้อนเดียวหมดไปกับรองเท้ารุ่นเดียวสีเดียว**
และไซส์หัว-ท้าย (US7, US12) มักค้างยาว

**ข้อสรุปเชิงกลยุทธ์: ล็อตแรกห้ามสต๊อกรองเท้าเป็นไซส์รัน** ใช้ pre-order / สั่งตามออเดอร์แทน
แล้วเอาทุนไปลงกับของที่หมุนเร็วและไม่มีปัญหาไซส์

อีกข้อที่ต้องรู้ก่อนวางแผนต่อ: **การเป็นตัวแทนจำหน่ายอย่างเป็นทางการของแบรนด์ใหญ่**
โดยทั่วไปมักมีเงื่อนไข เช่น จดทะเบียนนิติบุคคล ยอดสั่งขั้นต่ำ และบางแบรนด์ต้องมีหน้าร้าน
— **ข้อนี้ต้องโทรเช็คกับผู้จัดจำหน่ายในไทยเป็นราย ๆ ไป** อย่าเชื่อว่าเป็นแบบไหนจนกว่าจะได้คำตอบเป็นลายลักษณ์อักษร

## 2. สิ่งที่ยังไม่รู้ และต้องรู้ก่อนลงเงิน

ต้องได้คำตอบก่อนถึงจะวางแผนละเอียดกว่านี้ได้:

1. **เจ้าของวิ่งเองไหม / วิ่งมานานแค่ไหน / เคยลงงานอะไร** — ตัวนี้กำหนดทั้งหมดว่าจะเล่นเกม
   "ร้านที่รู้จริง" ได้หรือไม่ ถ้าไม่วิ่งเอง ต้องหาทางอื่นสร้างความน่าเชื่อถือ
2. **มีคนรู้จักในวงการวิ่ง/เทรลไหม** (กลุ่มซ้อม โค้ช ผู้จัดงาน ร้านเดิม)
3. **เวลาที่ให้ได้ต่อสัปดาห์** — ทำเต็มเวลา หรือทำควบงานประจำ
4. **รับความเสี่ยงได้แค่ไหน** — ถ้าจม 80,000 ฿ ใน 6 เดือนแล้วไม่คืน กระทบชีวิตไหม
5. **เป้าหมายจริงคืออะไร** — รายได้เสริม / แทนงานประจำ / สร้างแบรนด์ระยะยาว
   (สามอันนี้นำไปสู่แผนคนละแบบ)
6. **มีที่เก็บของไหม** (บ้าน/คอนโด พื้นที่เท่าไหร่)

## 3. โมเดลที่แนะนำ: 3 เฟส ไม่ข้ามขั้น

### เฟส 1 (เดือน 1–3) — "พิสูจน์ว่าขายได้ ก่อนจ่ายค่าสต๊อก"
- ขายของที่ **ไม่มีปัญหาไซส์** และหมุนเร็ว: เจล/อาหารระหว่างวิ่ง, ถุงเท้าวิ่ง, เป้น้ำ/ขวดนิ่ม,
  แถบสะท้อนแสง, ไฟฉายคาดหัว, เกลือแร่, ปลอกแขน/ปลอกน่อง, ที่กันแดด
- รองเท้า = **pre-order เท่านั้น** (ลูกค้าจ่ายก่อน แล้วค่อยสั่ง) — ทำให้เงินทุนหมุนติดลบ
  คือได้เงินก่อนจ่ายของ ซึ่งเป็นสิ่งที่ทุน <100k ต้องการที่สุด
- เสื้อผ้า = สั่งจำนวนน้อย เน้นไซส์กลาง (M/L) และรุ่นที่ไซส์ไม่ซับซ้อน
- เป้าหมายของเฟสนี้ไม่ใช่กำไร แต่คือ **ข้อมูล**: อะไรขายได้ ใครซื้อ ต้นทุนแอดต่อออเดอร์เท่าไหร่

### เฟส 2 (เดือน 4–8) — "ลงลึกในสิ่งที่ขายได้"
- เอากำไร + ข้อมูลจากเฟส 1 มาสต๊อกเฉพาะ SKU ที่พิสูจน์แล้ว
- เริ่มสต๊อกรองเท้า **เฉพาะรุ่นที่มีคนสั่ง pre-order ซ้ำ ๆ** และเฉพาะไซส์กลาง (US8–US10)
  ส่วนไซส์หัว-ท้ายยังใช้ pre-order
- เริ่มคุยขอเงื่อนไขที่ดีขึ้นจากซัพพลายเออร์ เพราะมียอดจริงไปโชว์แล้ว

### เฟส 3 (เดือน 9+) — "ตัดสินใจว่าจะโตทางไหน"
ทางเลือก: เป็นตัวแทนแบรนด์อย่างเป็นทางการ / ทำแบรนด์ตัวเอง (เริ่มจากถุงเท้า-เสื้อ ต้นทุนต่ำสุด) /
เปิดหน้าร้านเล็กเพื่อรับ fitting / ยังคงเป็นออนไลน์แต่ขยาย SKU

## 4. เลือกจุดยืน — อย่าเป็น "ร้านขายรองเท้าวิ่งทั่วไป"

แข่งราคากับร้านใหญ่ที่ซื้อทีละพันคู่ = แพ้แน่ ต้องเลือกมุมที่ร้านใหญ่ไม่สนใจทำ
เลือก 1 อัน (ไม่ใช่ทั้งหมด):

| จุดยืน | เหมาะเมื่อ | ข้อดี | ข้อเสีย |
|---|---|---|---|
| **เทรลเป็นหลัก** | เจ้าของวิ่งเทรลเอง | ชุมชนแน่น บอกต่อแรง คู่แข่งน้อยกว่าถนน | ตลาดเล็ก ดีมานด์ผูกกับปฏิทินงานวิ่ง |
| **เท้ากว้าง / นักวิ่งน้ำหนักมาก** | มีความรู้เรื่องสรีระ | ลูกค้าหาของยากมาก จงรักภักดีสูง | ต้องรู้จริง ให้คำแนะนำผิดคือจบ |
| **มือใหม่ครบเซ็ต** | ถนัดสอน/ทำคอนเทนต์ | ตลาดใหญ่ ออเดอร์เป็นชุด | ลูกค้าซื้อครั้งเดียวแล้วหาย |
| **ของจุกจิกครบที่สุดในไทย** | ขยันจัดการ SKU เยอะ | มาร์จิ้นดี ทุนต่อชิ้นต่ำ ซื้อซ้ำสูง | งานจิปาถะเยอะมาก |

**ข้อเสนอแนะ:** ถ้าเจ้าของวิ่งเทรลเอง → เอา "เทรล + ของจุกจิก" คู่กัน เพราะมันเสริมกัน
(คนเทรลซื้อเจล ขวดนิ่ม ไฟฉาย ซ้ำทุกเดือน) แต่ต้องตอบคำถามข้อ 2.1 ก่อน

## 5. แหล่งซื้อสินค้า — 4 ทาง เทียบให้เห็นความเสี่ยง

| ทาง | ทุนที่ต้องใช้ | มาร์จิ้น | ความเสี่ยง |
|---|---|---|---|
| ผู้จัดจำหน่ายแบรนด์ในไทย (ตัวแทนถูกต้อง) | สูง (มักมีขั้นต่ำ) | คุมโดยราคาแนะนำของแบรนด์ | ต่ำ — ของแท้ ตรวจสอบได้ |
| ผู้ค้าส่ง/ร้านที่ปล่อยต่อ | กลาง | บางกว่า | กลาง — ต้องตรวจที่มา |
| นำเข้าเอง / หิ้ว (grey market) | กลาง-สูง + ค่าภาษี | อาจดี | **สูง** — ของปลอมปน, แบรนด์อาจไล่เก็บ, ไม่มีประกันศูนย์ |
| ฝากขาย / pre-order ผ่านตัวแทน | ต่ำสุด | ต่ำสุด | ต่ำ — แต่คุมเวลาส่งไม่ได้ ซึ่งพังรีวิวได้ |

**ทุน <100k แนะนำ:** เริ่มจาก "ผู้ค้าส่ง/ฝากขาย/pre-order" ก่อน → พอมียอดจริงค่อยไปคุยเป็นตัวแทน

**เรื่องของปลอม — ห้ามประมาท:** รองเท้าวิ่งเป็นหมวดที่ของปลอมเยอะ
ขายของปลอมครั้งเดียวในกลุ่มวิ่ง = จบทั้งร้าน มาตรการขั้นต่ำ:
- เก็บใบเสร็จ/ใบกำกับจากต้นทางทุกล็อต
- ถ่ายวิดีโอแกะกล่องทุกออเดอร์ก่อนส่ง (กันเคลม + ใช้เป็นหลักฐาน)
- ถ้าซัพพลายเออร์ไม่ยอมออกเอกสารที่มา = ไม่ซื้อ ไม่ว่าราคาจะดีแค่ไหน

## 6. ตัวเลข

### 6.1 การจัดสรรงบ (ฐาน 80,000 ฿ — ปรับตามจริง)

| หมวด | จำนวน | เหตุผล |
|---|---|---|
| สต๊อกล็อตแรก (ของจุกจิก + เสื้อผ้าไซส์กลาง) | 35,000 | ห้ามเกินนี้ในล็อตแรก |
| แพ็กเกจจิ้ง + ค่าส่งเริ่มต้น | 4,000 | กล่อง ซอง เทป สติกเกอร์แบรนด์ |
| คอนเทนต์ (ไฟ ฉากถ่าย ขาตั้ง) | 4,000 | มือถือพอ ไม่ต้องซื้อกล้อง |
| งบทดสอบโฆษณา | 12,000 | แบ่งเป็น 4 สัปดาห์ สัปดาห์ละ 3,000 |
| ค่าจดทะเบียน/ค่าธรรมเนียมเบ็ดเตล็ด | 3,000 | |
| **เงินสำรอง ห้ามแตะ** | **22,000** | ไว้ซื้อของเติมตัวที่ขายดี — นี่คือส่วนที่คนมักพลาด |

### 6.2 สูตร Unit Economics (กรอกด้วยเลขจริง)

```
กำไรขั้นต้นต่อออเดอร์ = ราคาขาย
                      − ต้นทุนสินค้า
                      − ค่าธรรมเนียมแพลตฟอร์ม + ค่าธุรกรรม   ← ต้องเช็คอัตราล่าสุดเอง
                      − ค่าส่ง (ส่วนที่ร้านออก)
                      − ค่าแพ็ก
                      − ค่าโฆษณาต่อออเดอร์ (CAC)
```

**กติกาตัดสินใจ:** ถ้ากำไรขั้นต้นต่อออเดอร์ **ติดลบ** หลังหักค่าแอดแล้ว → หยุดยิงแอดทันที
ไม่ต้องรอ "ยอดจะโตแล้วดีเอง" มันไม่ดีเอง

### 6.3 จุดคุ้มทุน

```
ออเดอร์/เดือนที่ต้องได้ = ค่าใช้จ่ายคงที่ต่อเดือน ÷ กำไรขั้นต้นต่อออเดอร์
```

ตัวอย่างสมมติ: ค่าคงที่ 8,000 ฿/เดือน, กำไรขั้นต้น 400 ฿/ออเดอร์ → ต้องได้ **20 ออเดอร์/เดือน**
(ยังไม่รวมค่าแรงตัวเอง — ถ้าจะคิดค่าแรงตัวเองเดือนละ 15,000 ฿ ต้องได้ ~58 ออเดอร์/เดือน)

ให้คำนวณเลขนี้ก่อนเปิดร้าน แล้วถามตัวเองว่าตัวเลขนั้น **สมจริงไหมในเดือนที่ 3**

## 7. ช่องทางขายและการตลาด

**ช่องทาง (เปิดตามลำดับ ไม่เปิดพร้อมกันหมด):**
1. เพจ Facebook + กลุ่มวิ่ง/เทรล — คนวิ่งไทยอยู่ในกลุ่มเยอะ ต้นทุนเป็นศูนย์
2. TikTok / Reels — คอนเทนต์สั้นเรื่องอุปกรณ์ ทำให้เจอคนใหม่ได้เร็วที่สุดตอนนี้
3. Marketplace (Shopee/Lazada/TikTok Shop) — คนค้นหาเจอเอง แต่โดนหักค่าธรรมเนียมและโดนเทียบราคา
4. LINE OA — ไว้ปิดการขายและขายซ้ำ (ตรงนี้คือที่ที่กำไรอยู่จริง)

**คอนเทนต์ที่ได้ผลกับคนวิ่ง (เรียงตามความคุ้ม):**
- รีวิวใช้จริง ระยะจริง ("รองเท้าคู่นี้ผ่านมา 300 กม. แล้วเป็นยังไง") — ต้องวิ่งเองถึงทำได้
- เปรียบเทียบ 2 รุ่นแบบตรงไปตรงมา รวมถึงบอกว่ารุ่นไหน "ไม่เหมาะกับใคร"
- แก้ปัญหาเฉพาะ: เล็บดำ, พองเท้า, เสียดสี, เลือกไซส์ยังไงเมื่อซื้อออนไลน์
- ไลฟ์/โพสต์ช่วงก่อนงานวิ่งใหญ่ — ดีมานด์พุ่งตามปฏิทินงานวิ่ง ให้ทำปฏิทินงานวิ่งไทยทั้งปี
  แล้ววางแผนสต๊อก/คอนเทนต์ล่วงหน้า 4–6 สัปดาห์

**อาวุธที่ร้านใหญ่ทำได้ยาก:** ตอบแชทเองแบบรู้จริง + **นโยบายเปลี่ยนไซส์**
ปัญหาอันดับ 1 ของการซื้อรองเท้าวิ่งออนไลน์คือกลัวได้ไซส์ผิด ใครแก้ปัญหานี้ได้ชนะ
(แต่ต้องคิดต้นทุนค่าส่งกลับเข้าไปในราคาตั้งแต่แรก ไม่ใช่ใจดีแล้วขาดทุน)

## 8. เช็คลิสต์กฎหมาย/ภาษี (ต้องยืนยันกับหน่วยงานอีกครั้ง)

- [ ] **จดทะเบียนพาณิชย์ (พาณิชย์อิเล็กทรอนิกส์)** กับสำนักงานเขต/เทศบาล — ผู้ขายออนไลน์เข้าข่าย
      ต้องจด ให้เช็คกำหนดเวลาและเอกสารกับกรมพัฒนาธุรกิจการค้า
- [ ] เลือกรูปแบบ: **บุคคลธรรมดา** (เริ่มง่าย ภาษีขั้นบันได) vs **นิติบุคคล**
      (จำเป็นถ้าจะเป็นตัวแทนแบรนด์ ค่าใช้จ่ายบัญชีรายเดือนเพิ่ม)
- [ ] **VAT** — จดเมื่อรายได้ถึงเกณฑ์ที่กฎหมายกำหนดต่อปี ให้เช็คเกณฑ์ล่าสุดกับสรรพากร
- [ ] แยกบัญชีธนาคารร้าน/ส่วนตัว **ตั้งแต่วันแรก**
- [ ] เก็บใบเสร็จซื้อทุกใบ (ทั้งเรื่องภาษีและเรื่องพิสูจน์ของแท้)

## 10. KPI และเกณฑ์ go / no-go (ตั้งไว้ก่อน จะได้ไม่หลอกตัวเองทีหลัง)

ตัวเลขที่ต้องดูทุกสัปดาห์:
1. กำไรขั้นต้นต่อออเดอร์ (หลังหักทุกอย่างรวมค่าแอด)
2. CAC — ค่าโฆษณาต่อ 1 ออเดอร์
3. อัตราการระบายสต๊อก (sell-through) ต่อ SKU
4. อัตราซื้อซ้ำใน 90 วัน
5. เงินสดคงเหลือ ← ตัวที่ฆ่าธุรกิจเล็กจริง ๆ

**เกณฑ์ตัดสินที่เดือน 3:**
- กำไรขั้นต้นต่อออเดอร์ **เป็นบวก** และ sell-through ล็อตแรก **> 50%** → ไปเฟส 2
- กำไรบวกแต่ของค้าง → ปัญหาการเลือกสินค้า ให้แก้ SKU ไม่ใช่เพิ่มงบแอด
- กำไรติดลบหลังหักแอด → หยุดแอด กลับไปขายผ่านคอนเทนต์/กลุ่มอย่างเดียว
- เดือน 6 ยังไม่คุ้มค่าคงที่ → **หยุด** อย่าเติมเงินก้อนใหม่เพื่อ "เอาทุนคืน"

## 11. ความเสี่ยงหลักและวิธีลด

| ความเสี่ยง | ผลถ้าเกิด | วิธีลด |
|---|---|---|
| สต๊อกไซส์ผิดค้าง | เงินจมทั้งก้อน | ล็อตแรกไม่สต๊อกรองเท้า ใช้ pre-order |
| ได้ของปลอมมาขาย | จบทั้งร้าน กู้ชื่อไม่ได้ | ซื้อจากที่มีเอกสารที่มาเท่านั้น + วิดีโอแกะกล่อง |
| ค่าธรรมเนียมแพลตฟอร์มกินกำไร | ขายดีแต่ไม่มีกำไร | คำนวณค่าธรรมเนียมเข้าไปในราคาก่อนตั้งขาย + ดันคนไป LINE OA |
| สงครามราคากับร้านใหญ่ | มาร์จิ้นเหลือศูนย์ | ไม่แข่งราคา แข่งความรู้/บริการ/ความเร็ว |
| ดีมานด์ตามฤดูกาลงานวิ่ง | เงินสดขาดช่วงโลว์ซีซัน | ทำปฏิทินงานวิ่ง + กันเงินสดสำรอง |
| เจ้าของหมดไฟ (ทำคนเดียวทุกอย่าง) | ร้านค่อย ๆ เงียบ | ตั้งเวลาทำงานชัด + ทำคอนเทนต์ล่วงหน้าเป็นชุด |

## 12. สิ่งที่ควรทำก่อนใช้เงินบาทแรก

1. ตอบคำถามในข้อ 2 ให้ครบ
2. ทำสัปดาห์ที่ 1–3 ของแผน (สำรวจคู่แข่ง / คุยนักวิ่ง / ขอใบเสนอราคา) — ใช้เงินเกือบเป็นศูนย์
   แต่เปลี่ยนแผนนี้จาก "โครงร่าง" เป็น "แผนที่มีเลขจริง"
3. เอาต้นทุนจริงมาใส่สูตรข้อ 6.2 แล้วดูว่ากำไรต่อออเดอร์ยังเหลือไหม

ถ้าขั้นตอนที่ 3 ออกมาแล้วกำไรต่อออเดอร์บางมาก — นั่นคือคำตอบที่มีค่าที่สุด
และได้มาโดยยังไม่เสียเงินสักบาท
