# แผนเปิดร้านอุปกรณ์วิ่ง (ถนน) — เริ่มจากศูนย์ แบบทำควบงานประจำ

อัปเดต: 2026-08-08

**อินพุตที่เจ้าของให้มา**
- ทุนตั้งต้น: **ต่ำกว่า 100,000 บาท** (เงินที่จมได้จริง)
- ช่องทาง: **ออนไลน์เป็นหลัก** ไม่ผูกทำเล
- สินค้าที่อยากโฟกัส: รองเท้าวิ่ง + เสื้อผ้า/ชุดวิ่ง
- **ไอเดียตั้งต้นของเจ้าของ: ไปหารองเท้ามือสองมาขาย**
- **วิ่งเอง แต่ไม่วิ่งเทรล**
- **ไม่มีคอนเนกชันในวงการวิ่ง**
- **ทำควบงานประจำ**
- **เป้าหมาย: รายได้เสริม** (ไม่ได้จะแทนงานประจำ)

> เอกสารนี้แยกชัดเจนระหว่าง (ก) สิ่งที่เจ้าของบอกมา (ข) ตรรกะ/โครงสร้างที่วางให้
> (ค) ตัวเลขที่เป็น **สมมติฐาน ต้องไปเช็คของจริง** — ตัวเลขทุกตัวที่ไม่ได้มาจากเจ้าของ
> ให้ถือเป็นช่องว่างรอกรอก ไม่ใช่ข้อเท็จจริงของตลาด

## 1. อินพุตแต่ละข้อเปลี่ยนแผนยังไง

| อินพุต | ผลต่อแผน |
|---|---|
| **อยากขายรองเท้ามือสอง** | **ไอเดียนี้แก้ปัญหาที่ใหญ่ที่สุดของทุนน้อยได้จริง** (ไม่ต้องจมเงินกับไซส์รัน) แต่ไปสร้างปัญหาใหม่คือ **กินเวลาต่อคู่สูงมาก** ซึ่งชนกับ "ทำควบงานประจำ" → ดูข้อ 4 |
| วิ่งถนน ไม่วิ่งเทรล | **ตัดเทรลทิ้ง** — เทรลขายด้วยประสบการณ์จริงและความสัมพันธ์ในกลุ่ม ทำคอนเทนต์เทรลโดยไม่วิ่งเทรลจะถูกจับได้เร็ว |
| ไม่มีคอนเนกชัน | ห้ามพึ่งการบอกต่อในกลุ่มเป็นช่องทางหลักตอนเริ่ม ต้องพึ่ง "ดีมานด์ที่คนค้นหาเอง" + คอนเทนต์แทน |
| ทำควบงานประจำ | **เวลาคือทรัพยากรที่ขาดที่สุด ไม่ใช่เงิน** → ต้องออกแบบให้ใช้เวลาน้อยต่อออเดอร์ |
| รายได้เสริม | เกณฑ์ตัดสินคือ **"ได้กี่บาทต่อชั่วโมงที่ลงแรง"** ไม่ใช่กำไรรวม |

**สรุปทิศทาง:** ร้านอุปกรณ์**วิ่งถนน** ที่ขาย 2 ขาคู่กัน —
**รองเท้ามือสองคัดสภาพ** (กำไรต่อชิ้นสูง แต่หาของยากและกินเวลา) +
**ของสิ้นเปลือง/ของจุกจิก** (กำไรต่อชิ้นต่ำ แต่สั่งเพิ่มได้ตลอดและแพ็กเร็ว)
สองขานี้เสริมกันพอดี เหตุผลอยู่ในข้อ 5

## 2. ข้อจำกัดที่ทำให้ "รองเท้ามือหนึ่ง" ยังไม่ใช่ทางเลือกตอนนี้

รองเท้าใหม่มีปัญหาไซส์ × สี × เพศ (ต้นทุนเป็นสมมติฐาน ต้องขอใบเสนอราคาจริง):

| รายการ | จำนวน SKU | ต้นทุน/ชิ้น (สมมติ) | เงินที่จม |
|---|---|---|---|
| รองเท้า 1 รุ่น 1 สี ชาย US7–US12 | 6 คู่ | 2,500–4,000 ฿ | 15,000–24,000 ฿ |
| + ผู้หญิง US5–US9 | 5 คู่ | 2,500–4,000 ฿ | 12,500–20,000 ฿ |
| **รวม 1 รุ่น 1 สี** | **11 คู่** | | **27,500–44,000 ฿** |

ครึ่งหนึ่งของทุนหมดไปกับรองเท้า **รุ่นเดียว สีเดียว** และไซส์หัว-ท้ายมักค้างยาว

**มือสองไม่มีปัญหานี้เลย** เพราะซื้อทีละคู่ แต่ละคู่คือสินค้าชิ้นเดียว ไม่ต้องคอมมิตทั้งช่วงไซส์
นี่คือเหตุผลที่ไอเดียตั้งต้นของเจ้าของ **เข้าท่ากว่าที่คิด** สำหรับทุนระดับนี้

เสื้อผ้าก็ปัญหาเดียวกันแต่เบากว่า: ล็อตแรกเอาแค่ **M กับ L** และเลือกแบบที่ยืดหยุ่นเรื่องไซส์

**กติกาเหล็ก: ล็อตแรกไม่สต๊อกรองเท้ามือหนึ่ง** ไม่ว่าจะเจอดีลดีแค่ไหน

## 3. จุดยืน

เทรลถูกตัดออกแล้ว เหลือทางเลือกที่ทำได้จริง:

| ทางเลือก | เหมาะไหม | เหตุผล |
|---|---|---|
| **รองเท้ามือสองคัดสภาพ (ระบุระยะใช้งาน)** | ✅ **ขาหลัก** | ทุนต่อคู่ต่ำ ไม่มีปัญหาไซส์รัน กำไร % สูง และเจ้าของวิ่งเองจึงประเมินสภาพได้ |
| **ของสิ้นเปลือง/จุกจิกวิ่งถนน** | ✅ **ขาเสริม** | แพ็กเร็ว ซื้อซ้ำสูง มีของขายตลอดแม้หาของมือสองไม่ได้ |
| มือใหม่ครบเซ็ต | ⚠️ ทีหลัง | ตลาดใหญ่ แต่ต้องมี SKU ครบก่อน |
| รองเท้ามือหนึ่ง | ❌ ตอนนี้ | จมทุน ต้องเป็นตัวแทน |
| เทรล | ❌ | ไม่ได้วิ่งเอง + ไม่มีคอนเนกชัน |

## 4. รองเท้ามือสอง — ประเมินตรง ๆ

### 4.1 ข้อดีที่แท้จริง

- **ทุนต่อหน่วยต่ำ** ซื้อทีละคู่ ไม่ต้องจมเงินก้อน — ตรงกับทุน <100k ที่สุด
- **ไม่ต้องขออนุญาตแบรนด์** ไม่มียอดสั่งขั้นต่ำ
- **มาร์จิ้น % สูงกว่าของใหม่มาก** (ของใหม่ถูกล็อกด้วยราคาแนะนำและสงครามราคา มือสองไม่ถูกล็อก)
- **แต่ละคู่คือคอนเทนต์** รูปสวย ๆ ของรองเท้ารุ่นดังราคาครึ่งเดียว เป็นวัตถุดิบโซเชียลที่ดีมาก

### 4.2 ข้อเสียที่ต้องยอมรับ

- **กินเวลาต่อคู่สูงมาก** ทุกคู่ต้อง หา → ต่อรอง → ตรวจ → ทำความสะอาด → ถ่าย 8–10 รูป →
  วัดขนาดจริง → เขียนรายละเอียด → ลงประกาศ **แยกทีละคู่** ทำซ้ำไม่ได้เหมือนของใหม่
- **ธุรกิจนี้ติดที่ "หาของ" ไม่ใช่ "หาลูกค้า"** อยากขายเพิ่มก็สั่งเพิ่มไม่ได้ ต้องออกไปหา
  → รายได้ขึ้นกับเวลาที่ออกล่าของโดยตรง ซึ่งชนกับงานประจำ
- **เงินจมนานกว่าที่คิด** ของใหม่ขายไม่ออกยังลดราคาได้ มือสองบางคู่รอเป็นเดือนกว่าจะเจอคนไซส์ตรง
- **ของปลอมเยอะกว่าตลาดของใหม่** เพราะไม่มีใบรับรองจากต้นทาง
- **งานทำความสะอาด** เป็นแรงงานจริงที่คนมักลืมคิดเข้าไปในต้นทุน

### 4.3 ประเด็นที่ตัดสินว่าร้านจะรอดหรือพัง — อายุโฟม

**นี่คือหัวใจของการขายรองเท้าวิ่งมือสอง และเป็นจุดที่คนขายส่วนใหญ่เลี่ยงไม่พูดถึง**

รองเท้าวิ่งมีอายุการใช้งาน โฟมกลางพื้นยุบตัวตามระยะสะสม **หน้าตาภายนอกยังดูดีได้ทั้งที่โฟมตายแล้ว**
ขายรองเท้าโฟมตายให้นักวิ่งเอาไปวิ่งจริง = เสี่ยงทำให้เขาบาดเจ็บ และรีวิวจะพังตามมา

**ทางออก: แยกตลาดเป็น 2 กลุ่มให้ชัด แล้วบอกตรง ๆ**
- สภาพดี ระยะน้อย → ขายให้นักวิ่งเอาไปวิ่ง
- ผ่านการใช้มาเยอะ → ขายเป็น **รองเท้าใส่เดิน/ลำลอง** ราคาคนละระดับ และระบุชัดว่าไม่แนะนำให้วิ่ง

**เกณฑ์เกรดที่ควรประกาศไว้หน้าร้าน** (ตัวเลข กม. ข้างล่างเป็น **ข้อเสนอตั้งต้น**
ให้ปรับตามประสบการณ์ตัวเองและชนิดโฟมของแต่ละรุ่น ไม่ใช่มาตรฐานอุตสาหกรรม):

| เกรด | ระยะโดยประมาณ | แนะนำให้ใช้ทำอะไร |
|---|---|---|
| A | < 100 กม. / เกือบใหม่ | วิ่งได้เต็มที่ รวมถึงลงงาน |
| B | ~100–300 กม. | วิ่งซ้อมได้ เหมาะเป็นคู่สำรอง |
| C | ~300–600 กม. | ซ้อมเบา/เดิน ไม่แนะนำระยะไกล |
| D | > 600 กม. หรือประเมินไม่ได้ | **ขายเป็นรองเท้าลำลองเท่านั้น** ระบุชัดในประกาศ |

**วิธีประเมินระยะที่ทำได้จริง:**
- **ขอภาพหน้าจอระยะสะสมของรองเท้าคู่นั้นจาก Strava/Garmin ของผู้ขาย** — นักวิ่งหลายคนบันทึกไว้
  วิธีนี้แม่นที่สุดและแทบไม่มีร้านมือสองไหนทำ
- กดโฟมกลางพื้นดูว่าคืนตัวไหม
- ดูรอยย่นสะสมที่โฟม (crease) และการยุบด้านใดด้านหนึ่ง
- ดูดอกพื้นนอกบริเวณส้นและปลายเท้า
- ดูการยืดของหน้าผ้าบริเวณนิ้วหัวแม่เท้า

**และนี่คือจุดขายของร้าน:** ร้านที่ **ระบุระยะโดยประมาณ + ถ่ายรูปพื้นกลาง/พื้นนอกให้ดูทุกคู่ +
มีเกณฑ์เกรดเผยแพร่** คนขายมือสองรายบุคคลทั่วไปไม่ทำแบบนี้
เจ้าของทำได้เพราะวิ่งเอง — **นี่คือข้อได้เปรียบเดียวที่มีอยู่จริงตอนนี้ ให้ใช้มันให้เต็มที่**

### 4.4 แหล่งของ

| ทาง | ทุน | ข้อดี | ข้อเสีย/ความเสี่ยง |
|---|---|---|---|
| **รับฝากขาย (consignment)** จากนักวิ่ง | **0 ฿** | ไม่จมทุนเลย ได้ของหลากหลาย สร้างคอนเนกชันไปในตัว | ต้องมีคนเชื่อใจก่อน → ตอนเริ่มยังไม่มี ต้องสร้าง |
| ซื้อจากนักวิ่งรายบุคคล (กลุ่มขายของมือสอง) | ต่ำ | คุมราคาได้ เห็นของก่อนซื้อ | ใช้เวลาหาและนัดรับเยอะมาก |
| ประมูล/มือสองจากญี่ปุ่นผ่านตัวแทน | กลาง | ของสภาพดี ไซส์เอเชียตรงกับคนไทย | ค่าส่ง + ภาษี + เห็นแค่รูป เสี่ยงได้ของไม่ตรง |
| ซื้อยกมัด/กระสอบจากโกดังมือสอง | กลาง | ต้นทุนต่อคู่ต่ำสุด | ส่วนใหญ่ไม่ใช่รองเท้าวิ่ง คัดทิ้งเยอะ + **ต้องเช็คกฎหมายนำเข้าก่อน** (ดูข้อ 10) |

**เริ่มยังไงถ้าไม่มีคอนเนกชัน:** เริ่มจาก "ซื้อจากนักวิ่งรายบุคคล" ก่อน
พอมีรีวิวและมีคนรู้จักร้านแล้วค่อยเปิดรับฝากขาย ซึ่งเป็นโมเดลที่ดีที่สุดในระยะยาวเพราะทุนเป็นศูนย์

**เรื่องของปลอม:** ตลาดมือสองคือที่ที่ของปลอมซ่อนตัว
- ไม่ชัวร์ = ไม่รับ ไม่ว่าราคาจะดีแค่ไหน
- ขอรูปกล่อง/ป้ายในกล่อง/ใบเสร็จเดิมถ้ามี
- ถ่ายวิดีโอตอนรับของและตอนแพ็กส่งทุกคู่
- ขายของปลอมครั้งเดียวในวงการวิ่ง = จบทั้งร้าน กู้ชื่อไม่ได้

### 4.5 การทดสอบ 5 คู่ — ทำก่อนตัดสินใจอะไรทั้งสิ้น

ใช้เงินประมาณ 5,000–8,000 ฿ และเวลา 2–3 สุดสัปดาห์ เพื่อให้ได้ **ตัวเลขจริง** แทนการเดา

ซื้อรองเท้ามือสอง 5 คู่ (เลือกรุ่นยอดนิยม ไซส์กลาง US8–US10) แล้วจดทุกอย่าง:

| ต้องจด | ทำไม |
|---|---|
| เวลาที่ใช้หา + นัดรับ (นาที) | ตัวนี้มักกินเวลาที่สุดและคนลืมนับ |
| เวลาตรวจ + ทำความสะอาด | |
| เวลาถ่ายรูป + เขียนประกาศ | |
| ต้นทุนซื้อ + ค่าเดินทาง + ค่าอุปกรณ์ทำความสะอาด | ต้นทุนจริงไม่ใช่แค่ราคาซื้อ |
| ราคาที่ขายได้จริง (ไม่ใช่ราคาที่ตั้ง) | |
| **กี่วันกว่าจะขายออก** | ตัวชี้ว่าเงินจมนานแค่ไหน |

จากนั้นคำนวณ: **กำไรต่อคู่ ÷ ชั่วโมงที่ใช้ต่อคู่** แล้วเอาไปเทียบกับข้อ 7.3

ถ้าเลขออกมาแล้วไม่คุ้ม — เสียไป ~6,000 ฿ กับ 2 สุดสัปดาห์ แต่ได้คำตอบก่อนลงทุนทั้งก้อน
นั่นคือการทดสอบที่ถูกที่สุดที่ทำได้

## 5. ทำไมต้องมี "ของสิ้นเปลือง" ควบไปกับมือสอง

มือสองอย่างเดียวมีจุดอ่อน 3 อย่างที่ของสิ้นเปลืองอุดได้พอดี:

| จุดอ่อนของมือสอง | ของสิ้นเปลืองช่วยยังไง |
|---|---|
| หาของไม่ได้ = ไม่มีของขาย ร้านเงียบ | สั่งเติมได้ตลอด ร้านไม่มีวันว่าง |
| ลูกค้าซื้อรองเท้าปีละคู่-สองคู่ ไม่ซื้อซ้ำ | เจล/ถุงเท้า/เกลือแร่ ซื้อซ้ำทุกเดือน |
| ค่าส่ง/ค่าธรรมเนียมกินกำไรเมื่อขายชิ้นเดียว | พ่วงเพิ่มในตะกร้าเดียวกัน กำไรต่อออเดอร์ขึ้น |

**สินค้าสิ้นเปลืองที่ควรมี (15–25 SKU พอ):** เจล/อาหารระหว่างวิ่ง · เกลือแร่ · ถุงเท้าวิ่ง ·
แถบกันเสียดสี · สายรัดโทรศัพท์/เข็มขัดใส่ของ · ขวดนิ่ม · ปลอกแขน/ปลอกน่อง · แถบสะท้อนแสง ·
เชือกยางยืด · หมวก/ผ้าคาดหัว · **เชือกรองเท้า/แผ่นรองใน** (ขายพ่วงกับรองเท้ามือสองได้พอดี)

## 6. ออกแบบให้พอดีกับเวลาที่มี

สมมติมีเวลา **8–12 ชั่วโมง/สัปดาห์** (ต้องยืนยันตัวเลขนี้ — ดูข้อ 14)
จัดเป็นบล็อกตายตัว ไม่ใช่ทำแทรกทั้งวัน:

| งาน | เวลา/สัปดาห์ | วิธีทำให้เร็ว |
|---|---|---|
| **หา/รับของมือสอง** | 2–4 ชม. | รวมนัดรับหลายเจ้าในทริปเดียว เลือกซื้อจากคนที่ส่งไปรษณีย์ได้ |
| ตรวจ + ทำความสะอาด + ถ่ายรูป | 2–3 ชม. | ตั้งมุมถ่ายถาวรไว้ที่บ้าน ถ่ายรวดเดียวหลายคู่ ใช้เช็กลิสต์รูป 8 รูปเหมือนกันทุกคู่ |
| แพ็ก + ส่ง | 1–2 ชม. | รวมส่งสัปดาห์ละ 2 รอบ (เช่น พุธเย็น + เสาร์เช้า) |
| ตอบแชท | 2 ชม. | ข้อความอัตโนมัติ + คำตอบสำเร็จรูป 10 แบบ ประกาศเวลาตอบ เช่น 20:00–22:00 |
| คอนเทนต์ + บัญชี | 1–2 ชม. | ถ่ายคอนเทนต์รวดเดียววันอาทิตย์ |

**เคล็ดลับที่ประหยัดเวลาที่สุดในธุรกิจมือสอง: ทำเทมเพลตรูปและเทมเพลตคำบรรยายให้ตายตัว**
รูป 8 รูปมุมเดิมทุกคู่ (บน/ข้างซ้าย/ข้างขวา/หลัง/พื้นนอก/พื้นกลาง/ในรองเท้า/ป้ายไซส์)
+ ประกาศที่เว้นช่องให้เติมแค่ รุ่น/ไซส์/เกรด/ระยะ/ราคา → จาก 40 นาทีต่อคู่ เหลือ 10–15 นาที

**กติกาป้องกันหมดไฟ:**
- ไม่รับของเข้ามาเกินกำลังถ่าย/ลงประกาศ — ของที่ยังไม่ได้ลงขายคือเงินที่จมเฉย ๆ
- ประกาศรอบส่งชัดเจนตั้งแต่แรก แล้วทำตามให้ตรง ดีกว่าสัญญาส่งทุกวันแล้วพลาด
- ห้ามเบียดเวลาซ้อมของตัวเอง เพราะการวิ่งของเจ้าของ = ความน่าเชื่อถือ = สินทรัพย์ของร้าน

## 7. ตัวเลข

### 7.1 จัดสรรงบ (ฐาน 80,000 ฿ — ปรับตามจริง)

| หมวด | จำนวน | หมายเหตุ |
|---|---|---|
| **ทดสอบมือสอง 5 คู่ (ข้อ 4.5)** | 8,000 | **ใช้ก้อนนี้ก่อนก้อนอื่นทั้งหมด** |
| สต๊อกมือสองรอบจริง (หลังทดสอบผ่าน) | 25,000 | ทยอยซื้อ ไม่ซื้อทีเดียว |
| สต๊อกของสิ้นเปลืองล็อตแรก | 12,000 | 15–25 SKU |
| อุปกรณ์ทำความสะอาด + ถ่ายรูป (ไฟ ฉาก ขาตั้ง) | 4,000 | มือถือพอ ไม่ต้องซื้อกล้อง |
| แพ็กเกจจิ้ง + ค่าส่งเริ่มต้น | 4,000 | กล่องรองเท้าเปล่าสำหรับส่ง ต้องเผื่อ |
| งบทดสอบโฆษณา | 8,000 | มือสองพึ่งการค้นหาและคอนเทนต์มากกว่าแอด |
| จดทะเบียน/เบ็ดเตล็ด | 3,000 | |
| **เงินสำรอง ห้ามแตะ** | **16,000** | ไว้คว้าดีลดี ๆ ที่โผล่มากะทันหัน — ธุรกิจมือสองต้องมีเงินสดพร้อมเสมอ |

### 7.2 สูตร Unit Economics (กรอกด้วยเลขจริง)

```
กำไรต่อคู่ (มือสอง) = ราคาขายจริง
                    − ราคาซื้อ
                    − ค่าเดินทาง/ค่าส่งตอนรับของ
                    − ค่าทำความสะอาด/อุปกรณ์
                    − ค่าธรรมเนียมแพลตฟอร์ม + ค่าธุรกรรม   ← เช็คอัตราล่าสุดเอง
                    − ค่าส่งให้ลูกค้า (ส่วนที่ร้านออก)
                    − ค่ากล่อง/แพ็ก
```

### 7.3 ตัวเลขชี้ขาดสำหรับ "รายได้เสริม" — กำไรต่อชั่วโมง

```
กำไรต่อชั่วโมง = (กำไรรวมทั้งเดือน − ค่าใช้จ่ายคงที่) ÷ ชั่วโมงที่ลงแรงทั้งเดือน
```

**ตัวอย่างสมมติ (ต้องแทนด้วยเลขจากการทดสอบ 5 คู่):**
ขายมือสองได้ 12 คู่/เดือน × กำไร 700 ฿ = 8,400 ฿
+ ของสิ้นเปลือง 20 ออเดอร์ × 150 ฿ = 3,000 ฿
รวม 11,400 ฿ − ค่าคงที่ 3,000 ฿ = 8,400 ฿
ลงแรง 40 ชม./เดือน → **210 ฿/ชม.**

เอาเลขนี้เทียบกับทางเลือกอื่นที่ใช้เวลาเท่ากัน (OT, ฟรีแลนซ์, งานเสริมอื่น)
ถ้าต่ำกว่ามาก ให้ยอมรับตรง ๆ ว่าทำเพราะชอบ ไม่ใช่เพราะคุ้ม แล้วค่อยตัดสินใจว่าจะทำต่อไหม
ปีแรกเลขนี้ต่ำเป็นเรื่องปกติ แต่ถ้าเดือน 8 ยังไม่ขยับ = สัญญาณว่าโมเดลไม่เวิร์ก

## 8. โมเดล 3 เฟส

**เฟส 0 (เดือน 1) — ทดสอบ 5 คู่** ตามข้อ 4.5 ยังไม่เปิดร้านเป็นทางการ ยังไม่สั่งของสิ้นเปลือง
เป้าหมายเดียวคือได้ตัวเลข "กำไรต่อชั่วโมง" ที่เชื่อถือได้

**เฟส 1 (เดือน 2–5) — เปิดจริงแบบเล็ก**
มือสองเดือนละ 8–15 คู่ + ของสิ้นเปลือง 15–25 SKU · เปิด marketplace เป็นหลัก ·
เก็บข้อมูล: รุ่นไหนขายเร็ว ไซส์ไหนขายเร็ว เกรดไหนคนซื้อ นาทีต่อคู่เท่าไหร่

**เฟส 2 (เดือน 6–10) — ลงลึกในสิ่งที่พิสูจน์แล้ว**
เน้นซื้อเฉพาะรุ่น/ไซส์ที่ขายเร็ว · **เปิดรับฝากขาย (consignment)** เมื่อมีรีวิวพอให้คนเชื่อใจ —
ตรงนี้คือจุดที่ธุรกิจเริ่มโตได้โดยไม่ต้องเพิ่มทุน · เริ่มรับ pre-order รองเท้ามือหนึ่งถ้ามีคนถามซ้ำ ๆ

**เฟส 3 (เดือน 11+) — ตัดสินใจ**
คุ้ม → ขยาย: รับฝากขายเต็มรูปแบบ / เพิ่มบริการทำความสะอาดรองเท้า / เริ่มมือหนึ่ง
ไม่คุ้ม → ปิดให้สวย ระบายของ แล้วจบ อย่าลากยาว

## 9. หาลูกค้าจากไหน เมื่อไม่มีคอนเนกชัน

เรียงตามลำดับที่ควรเปิด — **อย่าเปิดพร้อมกันหมด** เพราะเวลาไม่พอ

1. **Marketplace (Shopee / Lazada / TikTok Shop) — เปิดก่อน**
   มีคนค้นหาอยู่แล้ว ไม่ต้องมีคอนเนกชัน เหมาะกับคนเริ่มจากศูนย์ที่สุด
   (**เช็คก่อนว่าแต่ละแพลตฟอร์มมีเงื่อนไขการขายสินค้ามือสองอย่างไร — บางที่มีหมวด/กติกาเฉพาะ**)
   ต้องคิดค่าธรรมเนียมเข้าไปในราคาตั้งแต่แรก อัตราเปลี่ยนบ่อย ให้ดูจากหน้า seller center เอง
2. **กลุ่มซื้อ-ขายรองเท้าวิ่งมือสองใน Facebook** — เป็นที่ที่ดีมานด์มือสองอยู่จริง
   เข้าไป **ในฐานะนักวิ่ง** ก่อน ตอบคำถามคนอื่นสัก 1–2 เดือน ค่อยเปิดตัวว่าขายของ
   (ยิงขายวันแรก = โดนแบนและเสียชื่อ) — และกลุ่มพวกนี้คือ **แหล่งซื้อของ** ด้วยในตัว
3. **TikTok / Reels** — คอนเทนต์แนว "รองเท้ารุ่นนี้มือสองราคาเท่านี้ เหลืออายุอีกกี่กิโล"
   เป็นคอนเทนต์ที่คนดูเยอะและทำได้เพราะวิ่งเอง
4. **LINE OA** — ปิดการขายและแจ้งของเข้าใหม่ กำไรจริงอยู่ตรงนี้เพราะไม่โดนหักค่าธรรมเนียม
   ธุรกิจมือสองเหมาะกับ LINE มากเพราะ **ของเข้าใหม่ทีละคู่ ต้องแจ้งคนที่รอไซส์นั้นอยู่**

**สร้างคอนเนกชันจากศูนย์ ทำได้เพราะวิ่งอยู่แล้ว:** ลงงานวิ่งเดือนละ 1 งาน คุยกับคนในงาน ·
เข้ากลุ่มซ้อมในพื้นที่ · ได้ทั้งลูกค้า **และแหล่งของ** ในทริปเดียว (นักวิ่งคือคนที่มีรองเท้าเก่าอยู่ในบ้าน)

## 12. KPI และเกณฑ์ go / no-go

ดูทุกสัปดาห์:
1. **กำไรต่อชั่วโมง** ← ตัวชี้ขาดสำหรับเป้าหมาย "รายได้เสริม"
2. กำไรต่อคู่ (หลังหักทุกอย่าง)
3. **จำนวนวันเฉลี่ยกว่าจะขายออก** ← ตัวชี้ว่าเงินจมนานแค่ไหน
4. อัตราคู่ที่ซื้อมาแล้วขายไม่ออก (ของตาย)
5. อัตราซื้อซ้ำใน 90 วัน (ส่วนใหญ่มาจากของสิ้นเปลือง)
6. เงินสดคงเหลือ
7. **จำนวนเรื่องร้องเรียนเรื่องสภาพสินค้า** ← ถ้าเกิน 1 ครั้ง ให้ทบทวนเกณฑ์เกรดทันที

**เกณฑ์ที่สัปดาห์ 6 (หลังทดสอบ 5 คู่):**
- ขายออก ≥ 3 ใน 5 คู่ ภายใน 3 สัปดาห์ และกำไรต่อชั่วโมงพอรับได้ → ไปต่อ
- ขายออกแต่กำไรต่อชั่วโมงต่ำมาก → ปัญหาคือเวลา ให้ทำเทมเพลตก่อนแล้วทดสอบใหม่อีก 5 คู่
- ขายไม่ออก → ปัญหาคือการเลือกของ (รุ่น/ไซส์/ราคา) ไม่ใช่การตลาด อย่ายิงแอดแก้

**เกณฑ์ที่เดือน 5:**
- ของตายเกิน 20% ของคู่ที่ซื้อมา → เลือกของยังไม่แม่น ให้แคบลงเหลือ 3–5 รุ่นที่รู้จริง
- ใช้เวลาเกินที่ตั้งไว้จนกระทบงานประจำหรือการซ้อม → ลดจำนวนคู่ต่อเดือน

**เกณฑ์ที่เดือน 10:** กำไรต่อชั่วโมงยังไม่ขยับขึ้นเลย → **หยุด** ระบายของ
อย่าเติมเงินก้อนใหม่เพื่อ "เอาทุนคืน"

## 13. ความเสี่ยงหลัก

| ความเสี่ยง | ผลถ้าเกิด | วิธีลด |
|---|---|---|
| **ขายรองเท้าโฟมตายให้คนเอาไปวิ่ง** | ลูกค้าบาดเจ็บ + รีวิวพัง + เสียชื่อถาวร | เกณฑ์เกรดข้อ 4.3 + รูปพื้นกลางทุกคู่ + แยกขายเป็นรองเท้าลำลองเมื่อควร |
| **ได้ของปลอมมาขาย** | จบทั้งร้าน | ไม่ชัวร์ไม่รับ + เก็บหลักฐานที่มาทุกคู่ |
| **หาของไม่ได้ ร้านเงียบ** | รายได้ขาดช่วง | มีขาของสิ้นเปลืองควบไว้ (ข้อ 5) |
| **เวลาไม่พอ / หมดไฟ** | ของกองอยู่แต่ยังไม่ได้ลงขาย | เทมเพลตรูป+คำบรรยาย, ไม่รับของเกินกำลังถ่าย |
| ของตาย (ซื้อผิดรุ่น/ไซส์) | เงินจม | เริ่มจากไซส์กลาง US8–10 และรุ่นยอดนิยมเท่านั้น |
| กระทบงานประจำ | เสียทั้งสองทาง | กันเวลาเป็นบล็อก ไม่ทำในเวลางาน เช็คสัญญาจ้าง |
| ค่าธรรมเนียม marketplace กินกำไร | ขายดีแต่ไม่มีกำไร | คิดค่าธรรมเนียมเข้าในราคาก่อนตั้งขาย + ดันลูกค้าไป LINE OA |
| ปัญหากฎหมายเรื่องนำเข้าของใช้แล้ว | ของถูกยึด/เสียค่าปรับ | เช็คก่อนสั่ง (ข้อ 10) เริ่มจากซื้อในประเทศก่อน |

## 14. ยังต้องรู้อีก (ตอบแล้วจะเจาะแผนได้ละเอียดขึ้น)

1. **ที่คิดจะไป "หา" รองเท้ามือสอง คือหาจากไหน** — มีแหล่งในใจอยู่แล้วหรือยัง
   (ซื้อจากนักวิ่ง / โกดังมือสอง / สั่งจากต่างประเทศ / รับฝากขาย) แต่ละทางคนละแผนเลย
2. **เวลาที่ให้ได้จริงต่อสัปดาห์กี่ชั่วโมง** — ข้อ 6 และ 7.3 ขึ้นกับตัวเลขนี้ทั้งหมด
3. **มีที่เก็บของไหม กี่ตารางเมตร** — รองเท้ากินพื้นที่มากกว่าของจุกจิกเยอะ
4. **วิ่งมานานแค่ไหน / ระยะต่อสัปดาห์ / เคยใช้รองเท้ารุ่นอะไรมาบ้าง** —
   กำหนดว่าจะประเมินสภาพรองเท้าได้แม่นแค่ไหน และจะพูดกับนักวิ่งกลุ่มไหนได้อย่างมั่นใจ
5. **ถ้าจม 80,000 ฿ แล้วไม่ได้คืนเลย กระทบชีวิตไหม**
6. **อยากได้รายได้เสริมเดือนละกี่บาท** — คำนวณย้อนกลับว่าต้องขายกี่คู่ และเวลาพอไหม
