## แท็บอาหาร

บันทึกอาหารรายมื้อ แล้วยอด kcal ของวันนั้นจะถูกบวกจากรายการอัตโนมัติ
ส่งต่อเข้าการคำนวณ TDEE จริงในแท็บติดตามเลย ไม่ต้องกรอกเลขรวมเองอีก

เพิ่มอาหารได้ 4 ทาง — ทุกทางมาจบที่กล่องเดียวกัน จะได้แก้ตัวเลขก่อนบันทึกเสมอ

| ทาง | ใช้กับ | ต้องมีอะไร |
|---|---|---|
| **ถ่ายรูป** | อาหารตามสั่ง ข้าวแกง อะไรก็ได้ที่ไม่มีฉลาก | Cloudflare Worker (ดู `worker/README.md`) |
| **สแกนบาร์โค้ด** | ของซอง ของกล่อง ของ 7-11 | ไม่ต้อง — ถาม Open Food Facts ฟรี ไม่ต้องมี key |
| **คลังอาหาร** | อะไรที่เคยกินมาแล้ว | ไม่ต้อง |
| **พิมพ์เอง** | รู้ตัวเลขอยู่แล้ว | ไม่ต้อง |

ทุกอย่างที่บันทึกโดยติ๊ก "เก็บเข้าคลัง" จะเข้าคลังอาหาร เรียงตามที่กินบ่อย กดครั้งเดียวใช้ซ้ำได้
บาร์โค้ดที่ Open Food Facts ไม่มี พอกรอกเองแล้วเก็บเข้าคลัง ครั้งหน้าสแกนปุ๊บเจอเลย — คลังของคุณถูกถามก่อนเสมอ

**รูปเก็บใน IndexedDB** ไม่ใช่ localStorage เพราะ localStorage มีที่ราว 5MB รูปเดียวก็เกือบเต็ม
รูปถูกย่อเหลือด้านยาว 900px ก่อนเก็บและก่อนส่ง

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า |
| `app.css` · `app.js` | สไตล์ และตรรกะทั้งหมด (คำนวณ TDEE, มาโคร, เทรนด์น้ำหนัก, กราฟ) |
| `pwa.js` | ปุ่มติดตั้ง, ลงทะเบียน service worker, แจ้งเวอร์ชันใหม่ |
| `sw.js` | แคชไฟล์ไว้ใช้ออฟไลน์ — **แก้ `VERSION` ทุกครั้งที่แก้ไฟล์อื่น** ไม่งั้นเครื่องที่ติดตั้งไว้จะยังเห็นของเก่า |
| `vendor/zxing.min.js` | ตัวอ่านบาร์โค้ดสำหรับ iPhone (Safari ไม่มี `BarcodeDetector`) โหลดตอนกดสแกนครั้งแรกเท่านั้น ไม่ได้แคชตอนติดตั้ง |
| `manifest.webmanifest` | ชื่อแอป ไอคอน สีธีม shortcut |
| `icon*.png` · `icon.svg` | ไอคอน (สร้างจาก `icon.svg`) |

## หน้า Artifact

`tools/tdee/index.html` คือไฟล์เดียวกันที่รวม CSS/JS เข้ามาไว้ในไฟล์เดียว สำหรับเผยแพร่เป็น Artifact

หน้า Artifact มี CSP ที่ห้ามต่อออกไปโฮสต์อื่น **ถ่ายรูปกับสแกนบาร์โค้ดจึงใช้ที่นั่นไม่ได้** — build script
ตั้งธง `window.__TDEE_ARTIFACT__` ให้ แอปจะปิดสองปุ่มนั้นพร้อมบอกเหตุผล แทนที่จะปล่อยให้กดแล้ว error

สร้างใหม่จากซอร์สในโฟลเดอร์นี้ด้วย

    python3 tools/tdee/build_artifact.py

อย่าแก้ `tools/tdee/index.html` ตรง ๆ — มันถูกเขียนทับทุกครั้งที่ build
