# แผน 90 วัน — จากศูนย์ สู่ลูกค้าคนแรกที่จ่ายเงินจริง (AI Service)

> เอกสารนี้เขียนจากคำถามว่า "อยากทำแบบเด็ก 16 คนนั้นบ้าง"
> ปรับให้ตรงกับเงื่อนไขจริง: **เริ่มจากศูนย์ ไม่มีเครือข่ายลูกค้า** และ
> **มีเวลา 5-10 ชม./สัปดาห์**

---

## 0. ตั้งเป้าให้ตรงกับความจริงก่อน

งบเวลาทั้งหมดของ 90 วัน = **ประมาณ 65-130 ชั่วโมง** (5-10 ชม. × 13 สัปดาห์)
นั่นคือประมาณ **2-3 สัปดาห์ของงานฟูลไทม์** เท่านั้น

**เป้าหมายที่สมเหตุสมผลของ 90 วันนี้คือ:**

| เป้า | ตัวเลข |
|---|---|
| ลูกค้าที่จ่ายเงินจริง | **1 ราย** (2 ถือว่าดีมาก) |
| รายได้สะสม | 6,000 - 25,000 บาท |
| สิ่งที่ได้กลับมาที่มีค่ากว่าเงิน | case study 1 ชิ้น + คำแนะนำต่อ (referral) + รู้ว่าตลาดจ่ายเพื่ออะไรจริง |

**เป้าที่ไม่สมเหตุสมผลและจะทำให้เลิกกลางทาง:** เลียนแบบตัวเลข $25,000/เดือน
Ty Chen ใช้เวลาสะสมทักษะการค้าตั้งแต่ 9 ขวบ และทำเต็มเวลาช่วงปิดเทอม
ตัวเลขนั้นเป็นการตลาดของโพสต์ ไม่ใช่ baseline

**กฎเหล็กข้อเดียวของ 90 วันนี้:**
> ห้ามสร้างอะไรที่ยังไม่มีคนบอกว่าเขาจะจ่ายเงินให้
> บทเรียน 20 ล้านวิว → ขายได้ 2 ชิ้น คือบทเรียนนี้

## 1. เลือก Niche (สัปดาห์ที่ 1)

ตอนไม่มีเครือข่าย ความได้เปรียบเดียวที่เหลือคือ **เลือกกลุ่มที่หาเจอง่าย
มีเงิน และเจ็บปวดแบบมองเห็นได้จากภายนอก**

### เกณฑ์คัด niche (ต้องผ่านครบ 4 ข้อ)

1. **มีเงินจ่ายอยู่แล้ว** — สังเกตจากการที่เขา *ยิงโฆษณา* อยู่ (ถ้ายอมจ่ายค่าแอด
   แปลว่างบการตลาดมี และเขาคิดเป็นตัวเลข)
2. **1 ลูกค้าที่หลุดมือ = เงินก้อน** (หลักพันถึงหลักหมื่น ไม่ใช่หลักสิบบาท)
3. **ความเจ็บปวดมองเห็นจากข้างนอกได้** — คุณต้องพิสูจน์ปัญหาเขาได้โดยไม่ต้องขออนุญาต
4. **มีเป็นร้อยรายในจังหวัดคุณ** — เพื่อให้ยิงซ้ำได้เมื่อเจอสูตรที่ใช่

### ตัวเลือกที่ผ่านเกณฑ์ (เรียงตามความแนะนำ)

| Niche | ทำไมถึงเข้าเกณฑ์ | ข้อควรระวัง |
|---|---|---|
| **คลินิกเสริมความงาม / ทันตกรรม / คลินิกผิวหนัง** | ยิงแอดหนัก, 1 เคส = 3,000-50,000 บาท, ลูกค้าทักผ่าน LINE แล้วแอดมินตอบไม่ทัน | มีคู่แข่งเอเจนซี่เยอะ ต้องขายด้วยความเร็ว/ราคาแทน |
| **นายหน้า/โครงการอสังหา** | 1 lead = ค่าคอมหลักหมื่นถึงแสน, follow-up หลุดตลอด | วงจรขายยาว ต้องอดทน |
| **โรงเรียนกวดวิชา / คอร์สเรียน / ฟิตเนส-สตูดิโอ** | จ่ายค่าแอด, ผู้ปกครองทักถามซ้ำ ๆ คำถามเดิม | งบน้อยกว่าคลินิก |
| **คลินิกสัตว์ / โรงพยาบาลสัตว์** | เจ้าของสัตว์ทักถามเยอะมาก, ค่าบริการสูง | เจ้าของมักเป็นหมอ ไม่ค่อยว่างคุย |

**คำแนะนำ: เลือกคลินิกความงาม/ทันตกรรม** และ **เลือกแค่อันเดียว**
เหตุผลคือทุกร้านมีปัญหาเดียวกันเป๊ะ ๆ → สคริปต์เดียว เดโมเดียว ใช้ยิงได้ทั้ง 200 ร้าน

> ⚠️ ห้ามทำหลาย niche พร้อมกัน ด้วยเวลา 5-10 ชม./สัปดาห์ คุณมีงบพอสำหรับสูตรเดียวเท่านั้น

## 2. เลือก Offer (สัปดาห์ที่ 1)

### Offer ที่แนะนำ: "ระบบไม่ให้ลูกค้าหลุดจาก LINE"

ประกอบด้วย 3 ส่วน — ขายเป็นก้อนเดียว ไม่แยกขาย:

1. **ตอบทันทีใน LINE OA 24 ชม.** — ตอบคำถามซ้ำ ๆ (ราคา เวลาเปิด ที่จอดรถ
   โปรโมชั่น คิวว่างวันไหน) ด้วย AI ที่ป้อนข้อมูลจริงของร้าน
2. **ส่งต่อคนจริงเมื่อจำเป็น** — ถ้าลูกค้าถามเรื่องอาการ/ขอคุยหมอ/หงุดหงิด
   → เด้งเข้าแอดมินทันที พร้อมสรุปบทสนทนา (ข้อนี้สำคัญมาก คือสิ่งที่ทำให้เจ้าของกล้าใช้)
3. **ตามคนที่ทักแล้วเงียบ** — ทักกลับอัตโนมัติที่ 24 ชม. และ 72 ชม.
   นี่คือส่วนที่ *สร้างเงินเพิ่มให้เขาโดยตรง* และเป็นข้อที่ควรพูดถึงเป็นข้อแรกตอนขาย

### ทำไมต้องเป็น LINE ไม่ใช่ Voice AI แบบในโพสต์

Ty Chen ขาย AI โทรศัพท์ เพราะที่อเมริกาธุรกิจรับงานผ่านโทรศัพท์
**ที่ไทยลูกค้าทักผ่าน LINE** และ AI เสียงภาษาไทยยังคุณภาพไม่นิ่งพอที่จะขายได้สบายใจ
— อย่าเริ่มตรงนั้น

### ราคา

| | ลูกค้ารายที่ 1-2 (pilot) | รายที่ 3 เป็นต้นไป |
|---|---|---|
| ค่าติดตั้ง | 6,000 - 9,000 บาท | 15,000 - 25,000 บาท |
| ค่าดูแลรายเดือน | 1,500 - 2,500 บาท | 3,000 - 5,000 บาท |

**ตั้งค่ารายเดือนตั้งแต่ลูกค้าคนแรกเสมอ** — นี่คือบทเรียนสำคัญที่สุดจากเรื่องของ Ty Chen
เขาโดน 1-Click Deploy ฆ่าธุรกิจ "รับเซ็ตระบบ" ภายใน 1 เดือนครึ่ง
งานติดตั้งครั้งเดียวจบจะโดนเครื่องมือใหม่แทนที่เสมอ สิ่งที่แทนที่ยากคือ
**คนที่รู้จักธุรกิจเขา คอยดูแลและปรับให้เรื่อย ๆ**

**สคริปต์ขอราคา pilot (พูดตรง ๆ ได้เลย):**
> "ราคานี้เป็นราคาพิเศษสำหรับ 2 เจ้าแรกครับ ผมขอแลกกับ 2 อย่าง —
> ขออนุญาตเอาผลลัพธ์ไปเล่าเป็นตัวอย่าง (ไม่เปิดชื่อถ้าไม่สะดวก)
> กับถ้าใช้แล้วดี รบกวนแนะนำให้เพื่อนในวงการสัก 2 ร้านครับ"

## 3. ตารางเดินงาน 90 วัน

### 🔵 Phase 1 — สร้างของที่ใช้ขายได้ (สัปดาห์ 1-3 · ~25 ชม.)

**เป้าหมายเฟสนี้: มีเดโมที่กดดูแล้วเข้าใจใน 60 วินาที — ยังไม่ต้องมีลูกค้า**

**สัปดาห์ 1 (8 ชม.)**
- [ ] เลือก niche + จังหวัด/โซนที่จะยิง (2 ชม.)
- [ ] ทำลิสต์ร้านเป้าหมาย **60 ร้าน** ใน Google Sheet — จาก Google Maps + Facebook
      คอลัมน์: ชื่อร้าน / LINE OA มีไหม / เพจ FB / ยิงแอดอยู่ไหม (เช็คใน Meta Ad Library) /
      ชื่อเจ้าของ / สถานะ / วันที่ติดต่อ (4 ชม.)
- [ ] **ทัก LINE OA ของ 20 ร้านในลิสต์ ตอน 3 ทุ่ม** ถามคำถามลูกค้าจริง ๆ
      (เช่น "ราคาโปรแกรม X เท่าไหร่คะ คิววันเสาร์ว่างไหม")
      แล้วจดว่าใครตอบ ใครไม่ตอบ ตอบช้าแค่ไหน (2 ชม.)

> ข้อสุดท้ายคือหัวใจของแผนนี้ — มันคือทั้ง **การวิจัยตลาด** และ **บทเปิดการขาย**
> ในการกระทำเดียว คุณจะได้หลักฐานเป็นภาพหน้าจอว่าร้านไหนกำลังทำลูกค้าหลุดอยู่จริง

**สัปดาห์ 2-3 (16 ชม.)**
- [ ] สร้าง LINE OA ของตัวเอง (ฟรี) + ต่อ Messaging API
- [ ] สร้าง flow ใน n8n หรือ Make: LINE webhook → เรียก Claude API พร้อมข้อมูลร้าน
      → ตอบกลับ / ถ้าเข้าเงื่อนไข escalate → แจ้งเตือนแอดมิน
- [ ] เก็บทุกบทสนทนาลง Google Sheet
- [ ] ตั้ง follow-up 24 ชม. / 72 ชม.
- [ ] **ทำเดโมเป็น "ร้านสมมติ" ที่เหมือนร้านเป้าหมายมาก ๆ** ใส่ราคาจริง โปรจริง
      ที่ก๊อปมาจากเพจร้านจริง ๆ ในลิสต์
- [ ] อัดคลิปหน้าจอ **60-90 วินาที**: ทักเข้าไป → ตอบทันที → ถามเรื่องอาการ →
      เด้งหาแอดมิน → เงียบไป 1 วัน → ระบบทักตาม

**เครื่องมือ (เริ่มด้วยของฟรีทั้งหมด):**
LINE Messaging API (ฟรี) · n8n self-host หรือ Make free tier · Google Sheets ·
Claude API (ค่าใช้จ่ายจริงระดับหลักสิบบาท/เดือนตอนเดโม)

> ⛔ **ห้ามเด็ดขาดในเฟสนี้:** จดโดเมน ทำโลโก้ ทำเว็บไซต์ จดบริษัท ทำ pitch deck สวย ๆ
> ทั้งหมดนี้คือการหลบเลี่ยงงานที่น่ากลัวจริง ๆ ซึ่งคือการคุยกับคนแปลกหน้า

### 🟡 Phase 2 — หาลูกค้า (สัปดาห์ 4-9 · ~40 ชม.)

**เป้าหมายเฟสนี้: ติดต่อ 100 ร้าน → คุยจริง 8-12 ร้าน → ปิดได้ 1 ร้าน**

ด้วยเวลา 6-7 ชม./สัปดาห์ = **ติดต่อร้านใหม่ 15-20 ร้าน/สัปดาห์** (ไม่ใช่ 200 DM/วันแบบในโพสต์
— เขาทำเต็มเวลา คุณไม่ได้ทำ ดังนั้นต้องชนะด้วยความแม่น ไม่ใช่ปริมาณ)

**ขั้นตอนต่อ 1 ร้าน (ประมาณ 20 นาที):**

1. ทัก LINE OA ร้านเขาตอนกลางคืน ถามแบบลูกค้าจริง
2. รอ 24 ชม. → แคปหน้าจอผลลัพธ์ไว้
3. ส่งข้อความหาเจ้าของ (ทางเพจ FB / อีเมล / เดินเข้าไปถ้าอยู่ใกล้)

**สคริปต์เปิด (ใช้ตอนที่เขาไม่ตอบ):**

> สวัสดีครับ ผม [ชื่อ] ครับ
>
> เมื่อคืนวันที่ [วันที่] เวลา [เวลา] ผมทักไปทาง LINE ของร้าน ถามเรื่อง [หัวข้อ]
> ยังไม่ได้รับการตอบกลับครับ (แนบภาพ)
>
> ผมไม่ได้จะติเลยนะครับ — ร้านที่ผมทดลองทัก 20 ร้าน มี 14 ร้านที่เป็นเหมือนกัน
> เพราะกลางคืนไม่มีใครเฝ้าจอ ซึ่งเป็นเรื่องปกติมาก
>
> ผมทำระบบที่ตอบลูกค้าใน LINE ให้ทันทีตลอด 24 ชม. ด้วยข้อมูลจริงของร้าน
> ถ้าเป็นคำถามที่ต้องให้คนตอบ มันจะเด้งหาแอดมินพร้อมสรุปให้
> และถ้าลูกค้าทักแล้วหายไป มันจะทักตามให้เองครับ
>
> ผมทำตัวอย่างของร้านลักษณะเดียวกับร้านพี่ไว้แล้ว เป็นคลิป 1 นาที
> ขอส่งให้ดูเฉย ๆ ได้ไหมครับ ไม่ดูก็ไม่เป็นไรครับ

**สคริปต์เปิด (ใช้ตอนที่เขาตอบ — แปลว่าเขาใส่ใจ ยิ่งเป็นลูกค้าที่ดี):**

> สวัสดีครับ เมื่อคืนผมทักไปถาม [หัวข้อ] ทาง LINE ร้าน ได้คำตอบตอนเช้า
> ขอบคุณครับ — แสดงว่าร้านพี่ดูแลดีกว่าอีกหลายร้านที่ผมลองทักมาเยอะเลย
>
> ผมเลยอยากถามตรง ๆ ครับ ช่วงกลางคืนหรือช่วงที่แอดมินไม่ว่าง
> มีลูกค้าทักแล้วหายไปเยอะไหมครับ ...

**เมื่อได้คุย ให้ถามแค่ 4 คำถามนี้ (ห้ามพรีเซนต์ก่อน):**
1. เดือนหนึ่งมีคนทักเข้ามาประมาณกี่คน?
2. ในนั้นได้มาเป็นลูกค้าจริงกี่คน? แล้วที่หายไปเฉย ๆ ล่ะ?
3. ลูกค้า 1 คนที่ปิดได้ มูลค่าประมาณเท่าไหร่?
4. ตอนนี้ใครเป็นคนตอบ LINE แล้วเสียเวลาวันละกี่ชั่วโมง?

คำตอบข้อ 2 × ข้อ 3 = **ตัวเลขที่คุณจะใช้ปิดการขาย** ให้เขาเป็นคนพูดตัวเลขนั้นเอง
อย่าไปเดาแทนเขา

**ติดตามใน Sheet ทุกสัปดาห์:** ทักไปกี่ร้าน / ตอบกลับกี่ร้าน / นัดคุยได้กี่ร้าน / ปิดได้กี่ร้าน

**จุดตัดสินใจสัปดาห์ที่ 7:** ถ้าติดต่อครบ 60 ร้านแล้วยังไม่มีใครยอมนัดคุยเลย
→ **อย่าดันต่อ** ปัญหาไม่ได้อยู่ที่ความพยายาม แต่อยู่ที่ niche หรือ offer
ให้กลับไปทำสัปดาห์ที่ 1 ใหม่กับ niche ถัดไปในตาราง

### 🟢 Phase 3 — ส่งมอบ แล้วเปลี่ยนเป็นเงินก้อนถัดไป (สัปดาห์ 10-13 · ~25 ชม.)

**เป้าหมายเฟสนี้: ส่งมอบให้ลูกค้าคนแรกจนเขาประทับใจ แล้วดึง referral ออกมาให้ได้**

- [ ] **เก็บเงินค่าติดตั้งก่อนเริ่มงาน** (อย่างน้อย 50%) — ข้อนี้ไม่ต้องรู้สึกผิด
      คนที่ไม่ยอมจ่ายมัดจำ คือคนที่จะไม่ให้ข้อมูลคุณและจะหายไปกลางทาง
- [ ] ขอข้อมูลจริง: เมนูบริการ ราคา เวลาทำการ คำถามที่ลูกค้าถามบ่อย 20 ข้อ
      และ **ประวัติแชท 1 เดือนย้อนหลัง** (อันนี้มีค่าที่สุด)
- [ ] เซ็ตระบบ + ทดสอบ 1 สัปดาห์โดยให้แอดมินอ่านทุกข้อความก่อนส่งจริง

## 5. สิ่งที่จะทำให้พังบ่อยที่สุด (เรียงตามความน่าจะเป็น)

1. **ใช้เวลาไปกับการเรียนแทนการทัก** — ดูคลิป n8n ต่ออีก 10 ชม. รู้สึกปลอดภัยกว่าโดนเมิน
   แต่มันไม่พาไปไหน กฎ 90/10 ในโพสต์นั้นถูกต้อง **ถ้าสัปดาห์ไหนไม่ได้ทักร้านใหม่เลย
   ถือว่าสัปดาห์นั้นเสียเปล่า** ไม่ว่าจะทำอะไรไปก็ตาม
2. **สร้างระบบให้เจ๋งขึ้นเรื่อย ๆ ก่อนมีลูกค้า** — อาการเดียวกับ Kibon เป๊ะ ๆ
   เดโมแค่ต้องดี "พอให้เข้าใจ" ไม่ต้องดี "พอให้ภูมิใจ"
3. **เปลี่ยน niche ทุก 2 สัปดาห์** — ยังไม่ทันได้ข้อมูลพอจะรู้ว่าอะไรผิด
   ให้ยึดตัวเลข 60 ร้านเป็นเกณฑ์ตัดสิน ไม่ใช่ความรู้สึก
4. **ขายเป็นงานติดตั้งครั้งเดียวจบ** — จะโดนเครื่องมือสำเร็จรูปแทนที่ภายในไม่กี่เดือน
   เหมือนที่เขาโดน Hostinger 1-Click Deploy
5. **รับงานที่ทำไม่ได้เพราะอยากได้เงิน** — ด้วยเวลา 5-10 ชม./สัปดาห์
   ลูกค้า 1 รายที่เละจะกินเวลาทั้งไตรมาสและได้ referral ติดลบ

## 6. ข้อสมมติที่ใช้เขียนแผนนี้ (ยังไม่ได้ยืนยัน)

แผนนี้เขียนบนสมมติฐานต่อไปนี้ ถ้าข้อไหนไม่ตรง บอกมาแล้วจะปรับให้:

- งบลงทุนเริ่มต้นใกล้ ๆ ศูนย์ (แผนจึงใช้ของฟรี/ราคาถูกทั้งหมด)
- อยู่ในไทย และเข้าถึงธุรกิจท้องถิ่นได้ (เดินเข้าไปหา หรืออย่างน้อยโทร/ทักได้)
- สื่อสารกับลูกค้าเป็นภาษาไทย
- ไม่ติดข้อจำกัดเรื่องการรับงานเสริมจากงานประจำ
- ยังไม่ทราบระดับความถนัดด้านเทคนิค — ถ้าเขียนโค้ด/เชื่อม API เองไม่ไหว
  ให้ใช้ Make + LINE official connector ทั้งหมดแทน n8n จะช้ากว่าแต่ไม่ต้องเขียนโค้ด
