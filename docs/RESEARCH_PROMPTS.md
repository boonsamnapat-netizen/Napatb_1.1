## #1 — สำคัญที่สุด: TikTok Shop Affiliate Creator API ตอบฟิลด์อะไรบ้าง

> ปลดล็อก: กลยุทธ์ "ขายดีสุด" กับ "คอมเยอะสุด" จะรอดหรือตาย

```
ผมกำลังจะเขียนโค้ดเรียก TikTok Shop Affiliate Creator API (เวอร์ชัน 202405)
ช่วยเปิดเอกสารจริงที่ partner.tiktokshop.com/docv2 แล้วตอบให้ครบทุกข้อ

1. ลิสต์ endpoint ทั้งหมดใต้ /affiliate_creator/202405/ พร้อม HTTP method
   และคำอธิบายสั้น ๆ ว่าแต่ละตัวทำอะไร

2. มี endpoint ไหนที่ "ค้นหาสินค้าข้าม marketplace" ได้บ้าง (คือค้นสินค้าของร้าน
   คนอื่นที่เปิด open collaboration ให้ creator เอาไปปักตะกร้า) ไม่ใช่แค่ค้น
   สินค้าในร้านตัวเอง — ถ้ามี ขอชื่อ endpoint กับ request/response schema เต็ม ๆ

3. ใน response ของ endpoint ค้นสินค้านั้น มี 3 ฟิลด์นี้ไหม ชื่อฟิลด์จริงคืออะไร
   - ราคาสินค้า
   - จำนวนที่ขายไปแล้ว (units sold / sales count)
   - อัตราค่าคอมมิชชั่นของสินค้านั้น (per-product commission rate)
   ขอตัวอย่าง JSON response จริงจากเอกสารด้วย

4. คนไทยที่เป็นบุคคลธรรมดา (ไม่ได้จดบริษัท ไม่มีใบทะเบียนพาณิชย์) สมัคร
   TikTok Shop Partner Center ประเภท "Developer" แล้วสร้าง Custom app
   เพื่อ authorize บัญชี creator ของตัวเองได้ไหม ต้องใช้เอกสารอะไรบ้าง
   ขั้นตอนจริงเป็นยังไง

5. rate limit เท่าไหร่ และมีค่าใช้จ่ายไหม

กติกา: ตอบเฉพาะสิ่งที่เปิดหน้าเอกสารเจอจริง แนบ URL ทุกข้อ
ถ้าข้อไหนหาไม่เจอหรือเปิดไม่ได้ ให้บอกว่า "ไม่พบ/ยืนยันไม่ได้" ตรง ๆ
ห้ามเดาชื่อฟิลด์หรือชื่อ endpoint จากความจำเด็ดขาด — ผมจะเอาไปเขียนโค้ดจริง
เดาผิดแล้วผมเสียเวลาทั้งวัน
```

## #2 — Involve Asia / ACCESSTRADE TH: API ตอบอะไรกลับมา

> ปลดล็อก: เขียน `NetworkFinder.search()` ได้จริง

```
ผมเป็น affiliate คนไทย ทำ "ปักตะกร้า" ให้ Lazada TH และ TikTok Shop TH
กำลังจะเขียนโปรแกรมดึงข้อมูลสินค้าผ่าน affiliate network
ช่วยเปิดเอกสาร API จริงของทั้งสองเจ้าแล้วตอบ

A) INVOLVE ASIA (help.involve.asia, involve.asia/partners/api-overview)
B) ACCESSTRADE (support.accesstrade.global/api, accesstrade.in.th/product-api)

ตอบแยกทีละเจ้า ข้อเหมือนกัน:
1. บุคคลธรรมดา (ไม่จดบริษัท) สมัคร publisher แล้วได้ API key เลยไหม
   ขั้นตอนจริง + ฟรีหรือเสียเงิน
2. วิธี authenticate (API key header? JWT? HMAC? token อายุเท่าไหร่)
3. endpoint ที่ "ค้นหาสินค้า" ได้ — ชื่อ, method, พารามิเตอร์
   สำคัญ: มันเป็นการ query แบบ real-time หรือให้ URL ไฟล์ feed มาให้โหลด
4. response มีฟิลด์พวกนี้ไหม ชื่อจริงว่าอะไร:
   - ราคาสินค้า
   - จำนวนที่ขายไปแล้ว
   - อัตราคอมมิชชั่น -- และมันเป็นเรตของ "สินค้าชิ้นนั้น" หรือเรตของ
     "ทั้งแคมเปญ/หมวดหมู่" (ข้อนี้สำคัญมาก ถามให้ชัด)
   - ลิงก์ affiliate ที่ track ได้เลย
   ขอตัวอย่าง JSON response จริง
5. ทั้งสองเจ้ามี offer ของ Lazada Thailand และ TikTok Shop Thailand จริงไหม
   คอมกี่ % แต่ละหมวด
6. endpoint สร้าง affiliate link จาก product URL ธรรมดา

กติกา: ตอบเฉพาะที่เปิดเอกสารเจอจริง แนบ URL
หาไม่เจอให้บอกว่าหาไม่เจอ ห้ามเดาชื่อฟิลด์ ผมจะเอาไปเขียนโค้ดจริง
```

## #3 — Replicate: ชื่อโมเดล + ราคาจริง + input schema

> ปลดล็อก: config ที่กรอกไว้แล้วใน `config/affiliate.yaml` ถูกหรือผิด (ถูกที่สุดแล้วในตอนนี้ แต่ยังไม่ยืนยัน)

```
ผมจะเรียก Replicate API เพื่อสร้างวิดีโอสินค้าแนวตั้ง 9:16 ยาว 8 วินาที
จากรูปภาพนิ่ง 1 รูป (image-to-video) เรียกผ่าน REST ตรง ๆ ไม่ใช้ SDK

ช่วยเปิดหน้าโมเดลจริงบน replicate.com แล้วตอบ:

1. ตอนนี้มีโมเดล image-to-video ตัวไหนบ้างบน Replicate ที่ทำคลิป 8 วินาที
   อัตราส่วน 9:16 ได้ ขอ "model slug" ที่ถูกต้องเป๊ะ ๆ (เช่น owner/name)
   อย่างน้อย 3 ตัว: ตัวคุณภาพดีสุด / ตัวคุ้มราคา / ตัวถูกสุด

2. แต่ละตัว ขอ input schema เต็ม — ชื่อ parameter จริงทุกตัว
   โดยเฉพาะ: พารามิเตอร์รูปชื่ออะไร (image? start_image? first_frame?),
   รับ data URI base64 ได้ไหมหรือต้องเป็น URL,
   พารามิเตอร์ความยาวชื่ออะไรและรับค่าอะไรได้บ้าง (8 ได้ไหม),
   พารามิเตอร์อัตราส่วนชื่ออะไรและค่าที่ใช้ได้คืออะไร

3. ราคาจริงต่อ 1 การสร้าง ของแต่ละตัว (จากหน้าโมเดลหรือหน้า pricing ของ
   Replicate ไม่เอาจากบล็อก) คิดเป็นดอลลาร์ต่อคลิป 8 วิ

4. รูปแบบ response: POST /v1/predictions ตอบอะไรกลับมา, GET poll ตอบอะไร,
   ฟิลด์ output เป็น string หรือ array, ค่า status ที่เป็นไปได้มีอะไรบ้าง

5. URL ไฟล์ผลลัพธ์ (replicate.delivery) โหลดได้เลยโดยไม่ต้องใส่ header auth
   ใช่ไหม และอยู่ได้นานแค่ไหนก่อนหมดอายุ

6. license ของแต่ละโมเดล — เอาไปใช้เชิงพาณิชย์ (ทำคลิปขายของ) ได้ไหม
   มีลายน้ำติดมาไหม

กติกา: ราคาและชื่อ slug ต้องมาจากหน้าเว็บ Replicate จริงเท่านั้น แนบ URL
ห้ามตอบจากความจำ ถ้าเปิดหน้าไหนไม่ได้ให้บอก
```

## #4 — ปักตะกร้าอัตโนมัติทำได้จริงไหม

> ปลดล็อก: ถ้าคำตอบคือ "ไม่ได้" เรื่องโพสต์อัตโนมัติจบตรงนี้ ไม่ต้องคิดต่ออีกเลย

```
คำถามเดียว ตอบให้ชัด: TikTok Content Posting API สามารถ "แนบสินค้า
TikTok Shop เข้ากับวิดีโอ" ตอนโพสต์ได้หรือไม่ (ภาษาไทยเรียก "ปักตะกร้า"
คือให้คลิปมีไอคอนตะกร้าที่กดแล้วไปหน้าสินค้า และนับ commission ให้ creator)

ช่วยเปิด developers.tiktok.com/docs (Content Posting API) และเอกสาร
TikTok Shop Affiliate API แล้วตอบ:

1. ใน request body ของ Content Posting API (ทั้ง Direct Post และ Upload)
   มีฟิลด์สำหรับใส่ product id / anchor / showcase item ไหม ชื่ออะไร
   ถ้าไม่มี ให้บอกตรง ๆ ว่าไม่มี
2. ถ้าไม่มี — มี API ตัวอื่นที่แนบสินค้าเข้าคลิปที่โพสต์ไปแล้วได้ไหม
3. scope video.upload (ที่ส่งคลิปเข้า inbox ให้ creator กดโพสต์เอง)
   ยังโดนข้อจำกัดของ unaudited client ไหม (โพสต์ได้แบบ private เท่านั้น +
   จำกัด 5 users ต่อ 24 ชม.) หรือข้อจำกัดนั้นใช้กับ video.publish อย่างเดียว
4. การขอ scope video.upload ต้องผ่าน app review แบบเดียวกับ video.publish ไหม
   ต้องมีเว็บไซต์สาธารณะ + privacy policy ไหม
5. Terms of Service ของ TikTok ห้ามการโพสต์คลิป affiliate แบบอัตโนมัติไหม
   ยกข้อความจริงมาให้ดู

บริบท: ผมเป็น creator คนเดียว บัญชีเดียว ไม่ได้จดบริษัท ไม่มีเว็บไซต์
ตอบเฉพาะที่เปิดเอกสารเจอ แนบ URL ห้ามเดา
```

## #5 — Lazada: มี affiliate API จริงไหม (ความสำคัญต่ำสุด)

```
ช่วยหาคำตอบให้ชัดว่า Lazada มี "Affiliate API" ที่บุคคลทั่วไปสมัครใช้ได้จริงไหม

1. เปิด open.lazada.com/doc แล้วดูว่ามี API group ไหนเกี่ยวกับ affiliate
   หรือ product search ข้ามร้านบ้าง ลิสต์ชื่อ API group ทั้งหมดที่มี
2. สมัคร Lazada Open Platform ต้องใช้ใบทะเบียนพาณิชย์/นิติบุคคลไหม
   บุคคลธรรมดาไทยสมัครได้หรือไม่
3. "Lazada Affiliate Program" ในไทย (LazAffiliate) มี API ให้ใช้ไหม
   หรือเป็นแค่หน้าเว็บสร้างลิงก์เอง
4. ถ้าไม่มี API — คนไทยที่ทำ affiliate Lazada จริง ๆ เขาดึงข้อมูลสินค้า
   แบบอัตโนมัติกันยังไง ผ่าน network เจ้าไหน

ตอบเฉพาะที่เปิดหน้าเว็บเจอจริง แนบ URL ถ้าสรุปได้ว่า "ไม่มี" ก็บอกว่าไม่มี
อย่าไปหยิบข้อมูลจากบล็อกของ vendor ขายซอฟต์แวร์มาตอบ (พวก api2cart ฯลฯ)
เพราะข้อมูลชุดนั้นผมสงสัยว่าไม่จริง
```
