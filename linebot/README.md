# LINE assistant bot — บันทึกรายรับ-รายจ่าย

บอท LINE ที่พิมพ์สั้น ๆ แล้วบันทึกให้ รันบน Cloudflare Workers + D1

```
คุณ: ข้าวเช้า 50
บอท: 💸 ข้าวเช้า 50฿
     — วันนี้ จ่าย 50฿ · รับ 0฿
     ↳ ไม่ใช่รายจ่าย? พิมพ์ `ลบ` แล้วพิมพ์ใหม่พร้อมหน่วย เช่น `กาแฟ 120 บาท`

คุณ: จ่ายค่าไฟ 1,200 บาท กับค่าน้ำ 300 บาท
บอท: 💸 ค่าไฟ 1,200฿
     💸 ค่าน้ำ 300฿
     — วันนี้ จ่าย 1,550฿ · รับ 0฿

คุณ: สรุปเดือน
บอท: 📊 ส.ค. 2026
     💰 รับ 30,000฿
     💸 จ่าย 1,550฿
     คงเหลือสุทธิ 28,450฿

     หมวดที่จ่ายมากสุด:
        · ค่าน้ำค่าไฟ 1,500฿
        · อาหาร 50฿
```

## รอบนี้ทำอะไรได้ / ยังไม่ได้

| | สถานะ |
|---|---|
| บันทึกรายจ่าย | ✅ |
| บันทึกรายรับ | ✅ |
| สรุปรายวัน / รายเดือน + จัดหมวด | ✅ |
| ลบ / แก้ย้อนหลัง | ✅ |
| แชร์ให้เพื่อนใช้ (แยกบัญชีกันอัตโนมัติ) | ✅ |
| นับแคลอรี่ | ⛔ รอบถัดไป — บอทจะตอบว่ายังไม่รองรับ |
| to-do / แจ้งเตือนตามเวลา | ⛔ รอบถัดไป — บอทจะตอบว่ายังไม่รองรับ |

ข้อความที่เป็นการนัดหมาย เช่น `พรุ่งนี้ 2 ทุ่ม โทรหาแม่` **จะไม่ถูกบันทึกเป็นรายจ่าย 2 บาท**
บอทจะตรวจจับแล้วตอบว่ายังไม่รองรับ — ตั้งใจให้ปฏิเสธเสียงดัง ดีกว่าบันทึกผิดเงียบ ๆ

## คำสั่งทั้งหมด

พิมพ์ `ช่วย` ในแชทก็ดูได้

| พิมพ์ | ผล |
|---|---|
| `ข้าวเช้า 50` | รายจ่าย 50 บาท (เดาให้ + ชวนแก้ถ้ากำกวม) |
| `กาแฟ 120 บาท` | รายจ่าย — มีหน่วยแล้วไม่ต้องเดา |
| `เมื่อวานกินหมูกระทะ 350 บาท` | ลงวันที่เมื่อวานให้ |
| `ค่าไฟ 1200 บาท กับค่าน้ำ 300 บาท` | บันทึกทีเดียว 2 รายการ |
| `ได้เงินเดือน 30000` / `+5000 ขายของ` | รายรับ |
| `สรุป` / `สรุปเดือน` | ดูยอด |
| `ลบ` / `ลบ 3` | ลบรายการล่าสุด / ที่ 3 นับจากล่าสุด |
| `แก้ 1500` | แก้จำนวนเงินของรายการล่าสุด |

รองรับตัวเลขหลายแบบ: `1,200` · `1.2k` · `2หมื่น` · `๕๐๐` · `85บาท` (ติดกันไม่เว้นวรรค) · `หนึ่งพัน`

## ติดตั้ง

### 1. สร้าง LINE Official Account + Messaging API channel

ตั้งแต่ ก.ย. 2024 **สร้าง Messaging API channel ตรงจาก LINE Developers Console ไม่ได้แล้ว** ต้องเข้าทาง OA Manager

1. สมัคร LINE Business ID → สร้าง LINE Official Account ที่ https://manager.line.biz
2. ใน OA Manager → Settings → Messaging API → Enable
   - ตอนนี้ระบบจะให้เลือก **provider** — ⚠️ **เลือกแล้วเปลี่ยนไม่ได้อีกเลย** ตามเอกสารทางการของ LINE
3. คัดลอกไว้ 2 ค่า:
   - **Channel secret** (LINE Developers → Basic settings)
   - **Channel access token (long-lived)** (LINE Developers → Messaging API → Issue)
4. ปิด auto-reply ทิ้ง: OA Manager → Settings → Response settings → ปิด "Greeting message" กับ "Auto-response" ไม่งั้นบอทจะตอบซ้อนกับข้อความอัตโนมัติของ LINE

### 2. Cloudflare

```bash
cd linebot
npm install

npx wrangler d1 create napatb_tracker      # เอา database_id ไปใส่ใน wrangler.toml
npx wrangler d1 migrations apply napatb_tracker --remote

npx wrangler secret put LINE_CHANNEL_SECRET
npx wrangler secret put LINE_CHANNEL_ACCESS_TOKEN

npx wrangler deploy                        # จะได้ URL .workers.dev มา
```

### 3. ต่อ webhook

LINE Developers → Messaging API →
- **Webhook URL** = URL ที่ได้จาก `wrangler deploy`
- กด **Verify** (ต้องขึ้น Success)
- เปิด **Use webhook**

เสร็จแล้วเพิ่มบอทเป็นเพื่อนแล้วพิมพ์ `ข้าวเช้า 50` ได้เลย

### ดู log ตอนมีปัญหา

```bash
npx wrangler tail
```

## ข้อจำกัดที่ควรรู้ก่อนใช้จริง

**เรื่องโควต้าข้อความ (สำคัญที่สุด — มีผลตอนทำ reminder รอบหน้า)**

เอกสารทางการของ LINE ระบุว่า:
- **reply message ไม่นับโควต้า** → บอทตอบตอนคุณพิมพ์ = ฟรีไม่จำกัด ✅
- **push message นับโควต้า** และเมื่อเกินโควต้า LINE จะ **ไม่ส่งข้อความนั้นเลย** (ตอบ error กลับ ไม่ใช่คิดเงินเพิ่มอัตโนมัติ)
- **reply token ใช้ได้ครั้งเดียว ภายใน ~1 นาที** → เอามาตั้งเตือนล่วงหน้าไม่ได้ ต้องใช้ push เท่านั้น

แปลว่า **ฟีเจอร์แจ้งเตือนตามเวลาในรอบถัดไปจะกินโควต้าทุกครั้งที่เตือน** ควรดูโควต้าจริงของแพ็กเกจตัวเองก่อนวางแผน

> ⚠️ **ราคาและโควต้าของ LINE OA ในไทย ยังไม่ได้ยืนยัน** — แหล่งข้อมูลที่หาเจอขัดแย้งกัน
> (200 หรือ 300 ข้อความฟรี/เดือน) และเว็บ lineforbusiness.com เข้าไม่ได้จากที่พัฒนา
> **ต้องเปิด https://lineforbusiness.com/th/ เช็คเองก่อนตัดสินใจ** ตัวเลขในไฟล์นี้จึงไม่ระบุ

**เรื่อง parser**

ตัวแยกข้อความเป็น regex ล้วน ฟรี ทำงานทันที แต่มีขอบเขตที่ทะลุไม่ได้:

- `ข้าวมันไก่ 60` — บอทไม่รู้ว่าเป็นอาหาร จะเดาว่าเป็น **รายจ่าย** เสมอ แล้วบอกวิธีแก้ให้
  (ใส่หน่วยไปเลย `60 บาท` ก็จบ)
- เลขที่สะกดเป็นคำ ต้องมีอย่างน้อย 2 พยางค์ถึงจะนับ (`สามหมื่น` ✅ แต่ `แสน` เดี่ยว ๆ ไม่นับ)
  ตั้งใจแบบนี้เพราะภาษาไทยไม่มีช่องว่าง `แสน` ใน "แสนแพง" ไม่ใช่ 100,000
- คำบอกเวลาที่ติดท้ายคำอื่นถือเป็นส่วนของคำนั้น (`ข้าวเที่ยง` = อาหาร ไม่ใช่ 12:00)
- ประโยคปฏิเสธยังอ่านไม่ออก (`ไม่ได้ซื้ออะไรเลย`)

โครงสร้างโค้ดเผื่อที่ไว้ให้เสียบ AI เข้ามาช่วยเฉพาะเคสที่ regex ไม่มั่นใจแล้ว
(`needsConfirm` กับ field `parser` ในตาราง `entries` มีไว้เพื่อการนี้) — ยังไม่ได้ทำ
และควรวัดค่าใช้จ่ายจริงก่อน

**เรื่องที่ยังไม่ได้ทดสอบจริง**

โค้ดทั้งหมดทดสอบแบบ offline เท่านั้น — เครื่องที่พัฒนาต่อ `api.line.me` และ Cloudflare ไม่ได้
(proxy บล็อก) การยืนยัน signature, การเรียก reply API และ D1 บนคลาวด์ **ยังไม่เคยรันจริง**
ต้องทดสอบตอน deploy ครั้งแรกด้วยตัวเอง
